降 Loss 之路

深度学习思想史：从感知机到智能体

Author

yujid

1 欢迎来到《降 Loss 之路》

这是一本用实验重走深度学习研究史的交互书。它不从「Transformer 是什么」讲起，而从 1958 年的感知机讲起——因为研究思路没法被讲述，只能被重演。读者只有先被 RNN 的梯度消失折磨过，才能真正理解「Attention is All You Need」标题里那个 All You Need 的分量。

1.1 两条主线

历史主线（骨架）：每一章都是历史上的一次真实解题。上一代架构留下的问题，就是下一章的起点。读完你走过的不是知识点清单，而是从感知机到智能体这条路上每一次「发现问题 → 提出假设 → 实验验证 → 暴露新问题」的完整循环。

Loss 主线（分析工具）：每个架构改进，统一用一个度量来审视——它让什么 loss、在什么数据上、降得更便宜？架构史因此不是名词罗列，而是一部「降 loss 效率的进化史」。这个视角一直延伸到当下：SFT 是指令数据上的监督 loss，RLHF 是奖励变形后的 loss，推理模型是可验证奖励上的 loss——看懂了 loss，就看懂了模型的本质，也更容易判断未来的方向。

1.2 全书的弧线

时代 核心问题 主角
史前史（1943–1986） 神经元能学到什么？ 感知机、反向传播
黎明（1986–2015） 为什么深网络训不动？ ReLU、Dropout、BatchNorm、残差
卷积时代（1989–2016） 如何看懂图像？ LeNet、AlexNet、ResNet
序列时代（1948–2014） 如何建模变长与长程依赖？ n-gram、RNN、LSTM、seq2seq
注意力革命（2014–2019） 如何摆脱循环？ Attention、Transformer、GPT/BERT
规模时代（2019–2024） loss 随规模如何变化？ Scaling Laws、Chinchilla
对齐时代（2020–2025） 如何重塑输出分布？ SFT、RLHF、DPO、RLVR
智能体时代（2023–2026） Agent 能力从哪来？ 工具调用、轨迹训练、上下文工程

1.3 给谁读

会 Python、了解一点线性代数和微积分、没系统学过深度学习的人可以直接从头读；有 ML 基础的读者可以跳过 Part 0–1 的推导细节，但建议不要跳过各章的「停一停」练习——那才是这本书真正的核心体验。

1.4 实验与算力

每章都有可运行的从零实现实验，按算力需求分三级标注：

  • A 级：笔记本 CPU，分钟级。卷一全部、卷二大部分实验在此级别——这段历史本来就发生在小算力上，今天恰好可以完整复现。
  • B 级：免费 Colab T4，几十分钟。卷二中后期的语言模型实验。
  • C 级：提供预训练 checkpoint，读者只做加载与分析。

代码不散落在 notebook 里，而是随书生长成一个包 dlbook：每章把新实现的模型合入其中，后续章节直接 import 复用。读完这本书，你拥有的不是一堆笔记，而是一座自己一层层盖起来的微型深度学习史图书馆。

1.5 三卷出版计划

  • 卷一 · 根基与黎明（Part 0–3）：从感知机到能训练的深度卷积网络。
  • 卷二 · 序列、注意力与规模（Part 4–6）：从 n-gram 到 GPT-3 与 Chinchilla。
  • 卷三 · LLM、对齐与智能体（Part 7–9）：从 base model 到 agent，以及一套判断未来的框架。

每卷独立成书可用，写完一卷发布一卷。

1.6 与其他资源的关系

  • Dive into Deep Learning：交互书工程与全面性的范本，本书实验工程大量借鉴；
  • fast.ai：自顶向下教学设计的范本；
  • Karpathy · Neural Networks: Zero to Hero：从零造 LLM 的范本。

本书的差异点：用研究史做骨架、用 loss 视角做解剖刀，一路贯穿到智能体与前沿——目前没有一本书这样做。
