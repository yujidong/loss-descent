28  涌现之争：相变还是度量假象

2022 年，一篇论文列举了大模型”突然”获得的小能力：多位数算术、指令跟随、按字母表排序……规模跨过某个阈值，准确率从接近零跳到可用。“涌现能力”（emergent (Wei et al. 2022) abilities）成了年度热词，也成了”AI 风险不可预测”论的技术注脚。2023 年，斯坦福的 Schaeffer 等人泼了冷水：也许根本没有相变，只有度量方式的幻觉。把连续改善的概率装进”全对才算分”的盒子里，任何平滑过程都会被量出一个跳变。本章我们用 6.1 的四个模型当场重演这场争论的两造，并提炼出对一切能力声明都有效的度量纪律。

Tip算力需求

A 级：笔记本 CPU · 主实验约 3 分钟（复用 6.1 的尺寸扫描）。

  • 算力：千亿模型多起来，“下一个尺寸会解锁什么”成了赌注巨大的问题；
  • 数据：基准考试（BIG-Bench 一类）成为能力探针。但探针的校准没人细究；
  • 认知：涌现叙事同时喂养了两派。乐观派（更大=新智能）与风险派（不可预测的跳变）；一个科学问题变成了叙事战场；
  • 关键事实：Schaeffer et al. 的反驳方式极其朴素：换掉度量（连续的 token 概率替代离散的精确匹配），“相变”大多消失。方法论上的一次四两拨千斤。

28.1 本章问题

  1. 同一组模型、同一个任务，平滑度量与阶梯度量各自讲出什么故事？（四尺寸 × 双度量的对照实验）
  2. 哪些”涌现”是度量制造的、哪些可能是真的？（判别纪律）
  3. 这场争论对”用 benchmark 声明能力”的实践意味着什么？（连向卷三的评测章）

28.2 历史中的尝试（包括弯路）

涌现的发现（Wei et al., 2022）：横轴规模、纵轴精确匹配率的图表里，曲线长期贴零然后陡起。视觉冲击力极强，命名也考究（emergence，从复杂性科学借来的相变词汇）。

弯路一：把图表当机制。“曲线跳了”与”模型内部发生了相变”是两个命题；前者先得到后者才能成立。早期讨论常把二者混用，甚至引出”不可预测的危险跳变”的政策叙事。

反驳（Schaeffer et al., 2023 (Schaeffer et al. 2023)）：核心论证一条。非线性（尤其不连续）度量是跳变的制造机。若模型对每个 token 的正确概率平滑地从 0.51 涨到 0.99，“整串全对”的概率会从 \(0.51^n\) 跳到 \(0.99^n\)。对长序列这是从零到一的悬崖，而底层什么相变都没有。把度量换回连续的（每 token 对数概率），悬崖消失。

后续的拉锯：有研究指出部分能力在连续度量下仍有加速（“软涌现”）；也有人用更细的探针找到真跳变的候选。悬而未决是本章结尾的诚实状态。但度量纪律本身已经赢下：任何能力声明都要先过”换度量还成立吗”这一关。

缓一缓。争论的两造摆好了：Wei et al. 2022 给出”贴零然后陡起”的图表，并从复杂性科学借来”涌现”这个名字；Schaeffer et al. 2023 反驳说，非线性度量是跳变的制造机——每 token 正确率从 0.51 平滑涨到 0.99，“整串全对”的概率就会从近零跳到近一。双方都同意的一点是：度量纪律先行。

一个思想实验，先算后跑：

设模型对某 8 字符串每个位置的预测正确率统一为 \(p\)（随尺寸从 0.5 平滑升到 0.9）。

  1. 画出”整串精确匹配率 \(p^8\)“随 \(p\) 的曲线。它是平滑的吗？在哪个 \(p\) 区间最陡？
  2. 若把”能力获得”定义为”精确匹配率超过 50%“，这个阈值对应 \(p\) 的哪个小区间？一条平滑的 \(p\) 曲线如何被这套定义变成一次”觉醒”事件？
  3. 预测我们的四尺寸模型（loss 3.36/2.31/1.91/1.80）：用”每字符 argmax 正确率”与”4 字符窗口全对率”两种度量，各会讲出什么故事？

写完再运行。这一题答对了，本章的主实验对你就是一次复习。

28.3 核心思想

度量的数学决定了故事的形状。设底层能力为连续量 \(c\)（如每字符正确率），度量函数 \(M\) 把它映到报表：

  • 连续度量（loss、对数概率、校准准确率）：\(M(c) \approx c\)。故事是”平滑改善”；
  • 阶梯度量（精确匹配、阈值通过、多项选择全对）：\(M(c) = \mathbb{1}[c^n > \theta]\) 一类。\(n\) 越大（串越长、要求越苛刻），同样的 \(c\) 改善被放大成越陡的跳变。

这度量的选择先于结论：先定度量再看图，跳变与平滑都唾手可得。科学的纪律是：能力声明必须经受度量替换的稳健性检验。换两三种度量，结论仍在，才叫现象；只在一种度量下存在，那可能只是度量的影子。

对”风险叙事”的校正：度量假象论让”不可预测的相变”失去了一部分证据，但是，没有证明”一切皆平滑”。真正的突变若存在，其机制研究（而非图表）才是正途。审慎的立场是双门的：既不拿阶梯曲线贩卖神秘，也不拿平滑曲线否认质变。

缓一缓。本节立下一条纪律：能力声明必须经受度量替换的稳健性检验——换到连续度量下还在的才算现象，只在阶梯度量下存在的可能只是度量的影子。对风险叙事的双门立场同样重要：不拿阶梯曲线贩卖神秘，也不拿平滑曲线否认质变。

28.4 从零实现

复用 6.1 的四尺寸扫描（同数据、同配方），每个模型测两种度量：

import numpy as np

from dlbook.data.corpus import char_corpus, make_grammar_corpus
from dlbook.transformer import MiniGPT
from dlbook.utils import set_seed

set_seed(42)

arr_t = np.array(char_corpus(make_grammar_corpus(60000, seed=0))[0])
arr_v = np.array(char_corpus(make_grammar_corpus(12000, seed=1))[0])
V = len(char_corpus(make_grammar_corpus(60000, seed=0))[1])  # 词表取自完整训练文本
vb = np.stack([arr_v[s : s + 65] for s in np.random.default_rng(7).integers(0, len(arr_v) - 65, size=200)])


def train_and_measure(d_model, steps=1500, seed=0):
    heads = 2 if d_model <= 32 else 4
    m = MiniGPT(V, d_model=d_model, n_heads=heads, n_blocks=2, block_size=64, seed=seed)
    rng = np.random.default_rng(seed)
    for step in range(steps):
        lr = 0.15 * min(1.0, (step + 1) / 150) * (1 - 0.9 * step / steps)
        starts = rng.integers(0, len(arr_t) - 65, size=16)
        batch = np.stack([arr_t[s : s + 65] for s in starts])
        m.loss_and_backward(batch)
        m.step(lr, clip=1.0)
    loss = float(m.loss_on(vb))
    pred = m.forward(vb[:, :-1]).argmax(-1)   # 教师强制下的 argmax
    tgt = vb[:, 1:]
    char_acc = float((pred == tgt).mean())     # 度量一：更平滑
    exact4 = sum((pred[i, j : j + 4] == tgt[i, j : j + 4]).all()
                 for i in range(pred.shape[0]) for j in range(0, pred.shape[1] - 3, 4))
    exact4 /= pred.shape[0] * (pred.shape[1] // 4)  # 度量二：阶梯
    return loss, char_acc, exact4


report = {}
for d in (8, 16, 32, 64):
    report[d] = train_and_measure(d)
    print(f"d={d:3d}: loss={report[d][0]:.3f}  char_acc={report[d][1]:.3f}  exact4={report[d][2]:.4f}")
d=  8: loss=3.361  char_acc=0.226  exact4=0.0025
d= 16: loss=2.312  char_acc=0.313  exact4=0.0022
d= 32: loss=1.909  char_acc=0.439  exact4=0.0544
d= 64: loss=1.804  char_acc=0.421  exact4=0.0634

把三种度量放在一起看（注意第二列到第三列的换算）：

import matplotlib.pyplot as plt

ds = list(report)
fig, axes = plt.subplots(1, 3, figsize=(12, 3.5))
for ax, (idx, title) in zip(axes, [(0, "loss (smooth)"), (1, "per-char accuracy (smooth)"), (2, "4-char exact match (cliffy)")]):
    ax.plot(ds, [report[d][idx] for d in ds], "o-")
    ax.set_xlabel("model size")
    ax.set_title(title)
plt.tight_layout()
plt.show()

典型读数：

d loss（平滑） char_acc（平滑） exact4（阶梯）
8 3.36 0.23 0.000
16 2.31 0.31 0.002
32 1.91 0.44 0.054
64 1.80 0.42 0.063

三个版本的故事：loss 说”平滑改善，尾部收窄”（真话）；char_acc 说”爬升，尾段回落”（也是真话——0.44 到 0.42 的回落来自 argmax 在个别上下文上的翻转，而 loss 仍在改善；离散度量的这种抖动本身就是教材）；exact4 说”小模型一无是处，d=32 突然觉醒（27 倍跳变）“。同一组模型、同一次训练。用「停一停」的公式验算：d=16→32 的 char_acc 只涨了 1.4 倍，exact4 却涨了 27 倍（0.002→0.054）。\(n=4\) 次方放大器在起作用。

宣布涌现 vs 揭露度量，此刻只隔一句话的距离。

缓一缓。三个度量的三个故事：loss 平滑收窄（真话）；char_acc 爬升但尾段回落（argmax 在个别上下文翻转，loss 仍在改善——离散度量的小抖动值得如实报告）；exact4 量出 27 倍的”觉醒”（\(n=4\) 放大器）。同一组模型、同一次训练，故事取决于你用哪把尺子。

28.5 消融实验

放大器的旋钮：把阶梯度量的窗口从 4 调到 2 和 8，跳变的”锐度”怎么变？（窗口越长，\(n\) 次方放大越猛，悬崖越陡。同一种能力可以被量出任意陡峭的觉醒。）

def exactk(pred, tgt, k):
    hits = sum((pred[i, j : j + k] == tgt[i, j : j + k]).all()
               for i in range(pred.shape[0]) for j in range(0, pred.shape[1] - k + 1, k))
    return hits / (pred.shape[0] * (pred.shape[1] // k))

# 用已训好的最大两档对比窗口效应（重训 d=32 取预测矩阵）
heads = 2
m32 = MiniGPT(V, d_model=32, n_heads=2, n_blocks=2, block_size=64, seed=0)
rng = np.random.default_rng(0)
for step in range(1500):
    lr = 0.15 * min(1.0, (step + 1) / 150) * (1 - 0.9 * step / 1500)
    starts = rng.integers(0, len(arr_t) - 65, size=16)
    m32.loss_and_backward(np.stack([arr_t[s : s + 65] for s in starts]))
    m32.step(lr, clip=1.0)
pred32 = m32.forward(vb[:, :-1]).argmax(-1)
tgt = vb[:, 1:]
for k in (2, 4, 8):
    print(f"窗口 k={k}: d=32 的精确匹配率 = {exactk(pred32, tgt, k):.4f}")
窗口 k=2: d=32 的精确匹配率 = 0.1808
窗口 k=4: d=32 的精确匹配率 = 0.0544
窗口 k=8: d=32 的精确匹配率 = 0.0000

（对照心中预演：k=2 温和、k=8 接近归零。“能力是否存在”的答案不应依赖你把尺子刻度切多细，这就是度量纪律的全部。）

缓一缓。窗口旋钮把放大器拆开给你看：k 越长，\(n\) 次方放大越猛，悬崖越陡。“能力是否存在”的答案不应依赖尺子的刻度切多细——这就是度量纪律的全部。

28.6 本章 Loss 账本

问题 回答
在优化什么 loss？ 本章不优化。本章审问度量：loss 本身是最平滑的那把尺（这也是它成为全书主线的深层原因之一）
数据从哪来？ 同 6.1；评测窗口的选择就是”数据”的一部分
买到了什么能力？ 度量替换的稳健性纪律；对能力声明的免疫力和对营销图表的解毒剂
没买到什么？ “是否存在真突变”的终审。玩具不能裁决；这需要机制研究（卷三的 interpretability 一脉）
  • 阶梯度量家族 → 一切 exact-match 基准（数学、代码评测）、“通过率”式 KPI。读它们的跳变时先做本章的心算；
  • 度量纪律 → LLM 评测方法学的核心（污染检测、校准、多度量三角验证。9.2 的地基）；
  • “叙事战场”模式 → 涌现之争是 AI 议题被叙事化的样本：乐观派、风险派、方法论者各取所需。读史者的位置永远在证据的细度里；
  • \(n\) 次方放大器 → 多步推理任务（链越长越陡）与 8.2 的 agent 任务评测。阶梯效应在 agent 时代只会更夸张。

Schaeffer, R., Miranda, B. & Koyejo, S. (2023). Are emergent abilities of large language models a mirage? NeurIPS 2023.

  • 读什么：图 1–2（同一模型族在连续 vs 离散度量下的两组图。本章实验的原型）与第 3 节的形式化；
  • 跳过：全部实验的模型细节；
  • 历史注：先读 Wei et al. (2022) 的涌现图表（视觉冲击是真实的第一印象），再读本文的反驳。按时间顺序体验”被说服→被反驳”，是训练科学判断力的最好回放。再补一篇后续的中间派（如对”真加速”的检测尝试），体会悬而未决。

28.7 遗留问题

  1. 度量之争审问了”报表”，没审问”模型内部”。能力到底怎么在权重里组织起来的？（→ 卷三 interpretability，及 7.1 的 in-context 机制研究）；
  2. 平滑的 loss 与跳变的能力声明之间的张力，将在对齐时代以更尖锐的形式出现：我们对模型的评估，永远比模型本身粗糙（→ 7.3 的 reward hacking，9.2 的评测危机）。

缓一缓。两个未决问题通向卷三：能力在权重里如何组织（interpretability 的战场）；我们的评估永远比模型本身粗糙，这道缝隙在对齐时代会更尖锐（7.3 的 reward hacking、9.2 的评测危机）。度量之争审问了报表，报表之下的机制仍待审问。

28.8 练习

  1. 造轮子：实现”连续版精确匹配”。把 argmax 换成前 k 个预测含目标的比率（top-k 命中率），观察它在四尺寸下的曲线形态。它比 exact4 平滑多少？
  2. 预测再运行：把训练步数砍半重测三度量。阶梯度量的”觉醒点”怎么移动？（提示：loss 右移多少，\(n\) 次方把它放大多少。）
  3. 消融：给 char_acc 加 0.40 的阈值，宣布”能力获得”事件。四尺寸的事件序列是什么？再换 0.35 的阈值呢？阈值即叙事开关的亲手体验。
  4. 论文映射：用四问账本拆 Wei et al. 2022 与 Schaeffer et al. 2023 各一份。注意后者”买到”的是方法论（度量纪律），这类反驳型工作的价值如何在账本上体现？
  5. 进阶：形式化”放大器”：设每步正确率为 \(p\) 的独立近似下，推导精确匹配率 \(p^n\) 对 \(\log\) 尺寸的二阶导数，找出”最陡点”的 \(p^*\)（与 \(n\) 的关系），用我们的实测数据检验独立性假设在哪里失效（相邻字符相关）。
Note练习答案

练习 2：觉醒点右移（每档都需要更多步数达到同样的 \(p\)）；且窗口越长移得越多。“\(n\) 倍放大”对底层的任何移动都同样生效，这就是阶梯度量的放大镜本质。

练习 3：0.40 阈值下事件序列是 d=32 觉醒（0.23/0.31/0.44/0.42）；0.35 下 d=16 就”觉醒”。同一个数据，两种叙事，全凭阈值一刀。审稿人看到”阈值通过率”时的第一个问题应当是：阈值谁定的、为什么。

练习 5 提示：\(p^*\) 在 \(p \approx e^{-1/n}\) 附近最陡（对 \(n=4\)，\(p^* \approx 0.78\)）——注意这是独立性近似下的结论，假设各位置正确率同为 \(p\) 且相互独立。独立性失效于高频搭配（the 后面接空格几乎必然对），实测曲线比独立模型更”早熟”。
