20  word2vec：语义被压进向量

2013 年，Mikolov 等人在一篇技术报告里放出了一个”玩具”：不做任何下游任务，只让网络回答”这两个词是否常常相邻出现”，结果词向量自己长出了几何结构。king − man + woman ≈ queen。这篇没有炫技公式的论文成了 NLP 被引用最多的工作之一，“embedding”（嵌入）从此成为整个领域的通用货币。本章我们用一个结构透明的玩具语料，亲眼看着共现统计被压进几何，并诚实讨论那道著名的类比运算：辉煌与水分各占多少。

Tip算力需求

A 级：笔记本 CPU · 全部实验合计约半分钟。

  • 算力：word2vec 在单 CPU 上几小时就能在数十亿词上训练。简单到可以在笔记本复现是它横扫社区的直接原因；
  • 数据：Google News 语料（约 60 亿 token，词表限 100 万）。互联网文本第一次作为”语义原料”大规模入炉；
  • 认知：2013 年的 NLP 主流仍是特征工程 + 统计模型；word2vec 证明了无监督的表示学习可以在 NLP 兑现。深度学习入场的敲门砖；
  • 关键事实：同时代还有 GloVe (Pennington et al. 2014)（2014，斯坦福，共现矩阵分解）与更早的 LSA（1990，SVD）。“共现 → 几何”这个想法被反复发明，word2vec 的胜利是工程与时机（简单 + 快 + 到点）的胜利。

20.1 本章问题

  1. 不用任何标签，仅凭”哪些词一起出现”，向量空间里能长出什么结构？
  2. 类比运算 \(\vec{b} - \vec{a} + \vec{c}\) 为什么会近似成立？它在什么语料结构下可靠、什么情况下是统计幻象？

20.2 历史中的尝试（包括弯路）

分布假说（Harris 1954）：语言学的老直觉。“看一个词的同伴，就知道它的意义”（You shall know a word by the company it keeps, Firth 1957）。四十年来它是语言学格言，缺的是把它变成可计算几何的机器。

弯路一：词-文档共现矩阵。LSA（1990）对”词 × 文档”矩阵做 SVD。语义有了，但是，维度巨大、无法增量更新、且”文档”这个上下文单位太粗。

弯路二：概率模型的重装备。在 word2vec 之前，学界主流是复杂的概率主题模型（LDA 一族）。精确、优雅、慢。Mikolov 的反叛是把任务简到荒谬：一个词预测它的邻居（skip-gram），配上负采样，两行公式。审稿人一度觉得太简单，论文先以技术报告面世。

类比现象的发现本身是意外：作者们在调参时发现向量算术成立，才补了专门的评估（有名的 analogical reasoning 测试集）。重大能力常常在系统跑通后才被”发现”而非被设计。这个模式将在 6.1（GPT-3 的 in-context learning）重演。

缓一缓。三个弯路反衬一个”玩具”：词-文档矩阵给出了语义但维度巨大、无法增量更新；LDA 一族精确而缓慢；word2vec 把任务简到只剩”预测邻居 + 负采样”两行公式。类比现象本身是调参时的意外发现——重大能力常在系统跑通后才被看见，这个模式在 6.1（GPT-3 的 in-context learning）还会重演。

实验设计题：你要构造一个语料，使训练后 \(\vec{kitten} - \vec{cat} + \vec{dog} \approx \vec{puppy}\) 成立。

  1. 结构设计：语料必须满足什么共现性质，“成体→幼崽”才会成为空间中一个方向一致的位移？（提示：若 kitten 与 cat 的上下文分布只差一个系统的成分，位移才稳定。）
  2. 反例设计：什么样的语料会让类比失效？（提示：让 kitten 的上下文里混入与 dog 相关的成分。）
  3. 规模直觉：真实语言里，为什么”巴黎−法国+日本≈东京”比” kitten−cat+dog”更难稳定成立？

写下三问的答案再读下面的语料设计。它就是第 1 问的一种实现。

20.3 核心思想

skip-gram + 负采样：对语料里每个中心词 \(c\) 与其窗口内的上下文词 \(o\)，最大化

\[\log \sigma(\vec{u}_o \cdot \vec{v}_c) + \sum_{k=1}^{K} \log \sigma(-\vec{u}_{n_k} \cdot \vec{v}_c)\]

直观上：真实邻居的内积要大，随机抽的负样本内积要小。没有语法、没有任务、没有标签：唯一的信息来源是共现。

为什么共现会长出几何：内积是”共现强度的可微代理”。训练把高频共现对拉近、随机对推远。每个词的位置由它的上下文分布决定，而按分布假说，上下文分布就是语义。于是”语义相似 = 向量夹角小”从格言变成了定理（Levy & Goldberg 2014 (Levy and Goldberg 2014) 证明了 skip-gram 隐式分解的是移位正点互信息矩阵——“共现 → 几何”由此有了理论身份）。

类比 = 结构化的分布差。若”幼崽”与”成体”的上下文分布相差一个近似恒定的成分（幼崽词都多出现在 small、baby 语境），则位移 \(\vec{kitten} - \vec{cat}\) 在各词对间近似平行。类比是”分布差的规律性”在几何上的投影。它的水分也在这里：真实语言的分布差只在统计平均意义上平行，逐例使用必然翻车（见消融）。

缓一缓。把三段论记下来：内积是共现强度的可微代理；按分布假说，上下文分布就是语义；于是训练把”相似 = 夹角小”从格言变成可优化的目标。类比的几何解释（分布差的规律性）也提前交代了它的水分——真实语言的分布差只在统计平均意义上平行。

20.4 从零实现

语料用 make_analogy_corpus：四个成体-幼崽词对（cat/kitten、dog/puppy、bird/chick、cow/calf）在共享模板里出现。模板保证”成体→幼崽”的分布差恒定（停一停第 1 问的实现）：

import numpy as np

from dlbook.data.corpus import make_analogy_corpus
from dlbook.word2vec import SkipGram

encoded, vocab = make_analogy_corpus(n_sentences=1500, seed=0)
print(f"{len(encoded)} 句，词表 {len(vocab)} 词")

sg = SkipGram(len(vocab), dim=16, seed=0)
losses = sg.train(encoded, epochs=8, lr=0.05, window=2, n_neg=4)
print(f"loss: {losses[0]:.3f} -> {losses[-1]:.3f}")
1500 句，词表 32 词
loss: 1.758 -> 1.631

实验一：类比。 向量算术最近邻：

for a, b, c, gold in [
    ("cat", "kitten", "dog", "puppy"),
    ("dog", "puppy", "bird", "chick"),
    ("bird", "chick", "cow", "calf"),
]:
    w, s = sg.analogy(a, b, c, vocab)
    print(f"{b:>7} - {a:<5} + {c:<5} = {w:<7} (期望 {gold}, cos={s:.3f})")
 kitten - cat   + dog   = puppy   (期望 puppy, cos=0.993)
  puppy - dog   + bird  = kitten  (期望 chick, cos=0.971)
  chick - bird  + cow   = calf    (期望 calf, cos=0.984)

三条全中（余弦 0.97+）。实验二：相似结构。

print("kitten 的近邻:", [w for w, _ in sg.most_similar("kitten", vocab)])
print("cat   的近邻:", [w for w, _ in sg.most_similar("cat", vocab)])
kitten 的近邻: ['calf', 'puppy', 'chick', 'dog']
cat   的近邻: ['cow', 'dog', 'bird', 'field']

幼崽们互为近邻、成体们互为近邻。两个语义簇在空间里自然分开，没有任何监督信号要求过这一点。把两簇画出来（取前两维投影）：

缓一缓。把本节的三步复述一遍：设计语料（模板保证”成体→幼崽”的分布差恒定，正是「停一停」第 1 问的实现）；训练（负采样 skip-gram，loss 从 1.76 收窄到 1.63）；验证（三条类比全中、余弦 0.97 以上，幼崽簇与成体簇在没有任何监督的情况下自动分开）。

import matplotlib.pyplot as plt

adults, babies = ["cat", "dog", "bird", "cow"], ["kitten", "puppy", "chick", "calf"]
XY = sg.Win[[vocab[w] for w in adults + babies]]
centered = XY - XY.mean(axis=0)
U, S, Vt = np.linalg.svd(centered, full_matrices=False)
P = centered @ Vt[:2].T

plt.figure(figsize=(5.5, 4.5))
for i, w in enumerate(adults + babies):
    color = "tab:red" if w in adults else "tab:blue"
    plt.scatter(*P[i], c=color, s=80)
    plt.annotate(w, P[i], fontsize=11, xytext=(4, 4), textcoords="offset points")
plt.title("Adults (red) vs babies (blue): two semantic clusters")
plt.show()

20.5 消融实验

类比的水分检测：换一组没有平行结构的词做算术。例如 garden - cat + dog（两个名词的普通位移）：

for a, b, c in [("cat", "garden", "dog"), ("runs", "garden", "sleeps"), ("warm", "day", "sunny")]:
    w, s = sg.analogy(a, b, c, vocab)
    print(f"{b:>7} - {a:<7} + {c:<7} = {w:<7} (cos={s:.3f})")
 garden - cat     + dog     = field   (cos=0.992)
 garden - runs    + sleeps  = hill    (cos=0.992)
    day - warm    + sunny   = quiet   (cos=0.651)

结果一样”自信”地给出高余弦答案。但是，没有任何语义解释。这就是 2016 年前后学界对词向量类比的著名批评（Linzen 2016 等）：算术最近邻这个操作天然偏爱高余弦，它对无意义的题目也照答不误。评估方法本身可以制造能力的幻象。这堂课在 LLM 时代将以”基准污染”“答案泄漏”的形式放大一万倍（9.2 的伏笔）。

缓一缓。水分检测的结果值得记住：对 garden - cat + dog 这类无意义的题目，求解器照样”自信”地给出高余弦答案。算术最近邻天然偏爱高余弦，它不会对无意义的题目表示犹豫——评估方法本身可以制造能力的幻象。这堂课在 LLM 时代将以”基准污染”“答案泄漏”的形式放大一万倍（9.2 的伏笔）。

20.6 本章 Loss 账本

问题 回答
在优化什么 loss？ 负采样 skip-gram：真实共现 σ 内积最大化。一个把共现统计转成几何结构的 loss，无任何人工标签
数据从哪来？ 无标注语料。“数据从哪来”第一次有了便宜的答案：互联网本身
买到了什么能力？ 语义的向量表示：相似度、聚类、（结构良好时）类比；一切下游模型的输入货币
没买到什么？ 组合性（“bank river” 的歧义无解。一词一向量）；类比的可靠性（幻象）；句法与语用
  • 词向量 → LLM 的输入嵌入层与输出头（5.2）。token embedding 是 Transformer 唯一”带着进门”的组件，其余全部重新学习；
  • “共现→几何” → 检索（embedding 检索是 RAG 的地基，8.3）与推荐系统；
  • 类比幻象 → LLM 评测方法论的百年教训：先审评估，再信能力（6.3 的基准讨论、9.2）；
  • 无监督表示学习 → 预训练范式的第一块砖（3.3 的”特征可搬运”+ 本章”表示可自学”= 6.1 GPT 的两块奠基石）。

Mikolov, T., Sutskever, I., Chen, K., Corrado, G. & Dean, J. (2013). Distributed representations of words and phrases and their compositionality. NeurIPS.（word2vec 的正式版）

  • 读什么：第 2 节（skip-gram 与负采样，两页讲完整个方法）与第 4 节（类比的发现）；
  • 跳过：实现细节；
  • 历史注：配套读 Levy & Goldberg (2014)（证明 skip-gram ≈ 分解 PMI 矩阵，“神经方法其实是老朋友穿了新衣”的注脚）与 Pennington et al. (2014)（GloVe：干脆直接分解）。三篇合读，“简单方法 × 大数据”的威力与”理论解释随后赶到”的节奏都齐了。

20.7 遗留问题

  1. 词向量是静态的。同一个词在任何句子里都是同一个向量。随上下文变化的表示如何构造？（ELMo/GPT 的方向，6.1。需要先把”下一个词预测”做大做深）；
  2. 把两台 LSTM 一读一写接起来，能做翻译吗？瓶颈在哪？（→ 下一章 seq2seq）。

缓一缓。词向量是静态的：同一个词在任何句子里都是同一个向量，一词多义无处安放。把表示变成”随上下文变化”，需要先有一台能压住长程结构的序列模型——下一章的 seq2seq 与此后的 GPT 正是这条路。

20.8 练习

  1. 造轮子：把 skip-gram 换成 CBOW（上下文预测中心词，注意上下文向量要平均），在同语料上对照 loss 与类比成绩。
  2. 预测再运行：把负样本数 \(K\) 从 4 调到 0（纯正样本）与 32，类比与聚类各怎么变？（提示：负样本在”推远”谁。）
  3. 消融：把语料里”the {adult} is big / the {baby} is small”模板删掉（只留共享模板），类比还成立吗？亲手验证”分布差的恒定性”是类比的必要条件。
  4. 论文映射：用四问账本拆 GloVe。它把 word2vec 的”隐式分解”变成显式，账本上”买到”与”没买到”各怎么记账？
  5. 进阶：实现 Linzen 式检验。给类比求解器加上”最近邻必须显著近于次近邻”的置信门槛，统计真类比与伪类比（消融实验的题目）各自的门槛通过率。为”能力 vs 幻象”造一把尺子。
Note练习答案

练习 2：\(K=0\) 时所有向量被拉向同一点（退化，聚类消失）；\(K\) 过大则训练慢且低频词被过度推远。\(K\approx 5{-}20\) 是历史经验的甜点。负样本是几何的”斥力”来源，斥力过小则塌缩、过大则稀疏。

练习 3：类比大概率失效或大幅退化。“大/小”模板正是提供恒定分布差的成分。这个消融是”类比 = 结构化分布差”论断的最小验证。

练习 5 提示：真类比的余弦分布应显著高于伪类比（可分性），但是，重叠尾部一定存在。置信门槛把”何时可信”变成可操作的统计问题。这把尺子的思想就是后来 LLM 评测的校准与 abstention。
