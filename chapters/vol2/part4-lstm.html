19  LSTM：让梯度存活的门控设计

上一章的尸检报告写着：60 步的 BPTT，梯度衰减 56 个数量级。本章讲 1997 年的手术。Hochreiter 与 Schmidhuber 的长短期记忆网络（LSTM）。手术的核心只有一句话：在循环单元里修一条恒等传送带（细胞状态 \(c\)），让信息与梯度可以近乎无损地穿越时间；再装三扇门（读、写、忘）控制上下传送带的时机。这个设计统治了序列建模二十年。从 2015 年谷歌翻译上线到 2016 年的 WaveNet 之前，你用过的每一句机器翻译背后都是它。但是，本章也会诚实记录：门控买到的是梯度通道，不是免费的训练顺利。LSTM 的真实战功同样依赖一整套工程配方。

Tip算力需求

A 级：笔记本 CPU · 全部实验合计约 1 分钟。

  • 算力：LSTM 的实用化（2010 年代语音识别、2015 年谷歌翻译）依赖 GPU。结构 1997 年就位，生态晚了十五年；
  • 数据：语音与机器翻译的平行语料是 LSTM 的主场。序列对序列、长程依赖密集；
  • 认知：1997 年的论文标题是”Long Short-Term Memory”。长与短并列，因为核心主张正是同时处理长短两种时间尺度；
  • 关键事实：原版 LSTM 没有遗忘门（只有输入与输出门）。遗忘门是 Gers 等人 2000 (Gers et al. 2000) 年补上的。伟大架构也是逐步长出来的，1.0 版本常常缺一块关键零件。

19.1 本章问题

  1. 门控结构在数学上如何改善梯度流？（梯度剖面的正面对比。先看机制兑现）
  2. 遗忘门为什么是三扇门里最要命的？（记忆保持的乘法账）
  3. 诚实的问题：梯度通道修好了，训练就顺了吗？（本章的答案会出乎一部分人的意料）

19.2 历史中的尝试（包括弯路）

从诊断到手术：Hochreiter 1991 年的硕士论文（2.2 章的主角）诊断了梯度消失；1997 年他与 Schmidhuber 拿出解药。同一人先写病历再开刀。研究史上罕见的完整闭环。

原版的缺陷与生长：1997 版只有输入门与输出门，细胞状态一旦写入便几乎不可清除。长期任务反而被旧记忆污染。Gers, Schmidhuber & Cummins (2000) 补上遗忘门，后来还发现遗忘门偏置初始化为正（让”记住”成为默认）对长程任务至关重要。GRU (Cho et al. 2014)（2014）再做减法（两扇门、合并状态），在许多任务上打平。二十年间的所有变体都在同一设计空间里腾挪：传送带 + 门。

弯路：把 LSTM 当万金油。2010 年代中叶的论文常报告”LSTM 在一切序列任务上碾压”。但对照实验常常用了不同等的训练配方（截断长度、裁剪阈值、学习率日程）。LSTM 的战功里有一定比例属于调参劳动而非结构本身。本章的诚实实验会亲手摸到这条边界。

你已看过 RNN 的坠崖剖面。现在自己设计手术。约束：只准在单元内部加结构，不准改训练算法。三个引导问题：

  1. 3.2 章的残差连接给前馈网修了”不经过连乘的恒等路”。时间维的对应物应该长什么样？（写出 \(c_t = ?\) 的递推，使 \(\partial c_t / \partial c_{t-1}\) 尽量接近 1）；
  2. 恒等传送带的危险是什么。垃圾信息也永远删不掉。你需要什么机构来删除记忆？（这就是遗忘门。注意 1997 年原版恰恰漏了它）；
  3. 传送带上放着记忆，但是，单元对外输出的是 \(h_t\)。还需要一扇什么门？

三问答完，你设计出的结构应当与 LSTM 相差无几。好的架构是可以被问题重新发明出来的，这也是「停一停」栏目的终极含义。

19.3 核心思想

LSTM 的全部递推（\(x_t\) 是输入，\(\sigma\) 是 sigmoid）：

\[ \begin{aligned} i_t &= \sigma(W_i x_t + U_i h_{t-1} + b_i) & \text{写入多少（输入门）}\\ f_t &= \sigma(W_f x_t + U_f h_{t-1} + b_f) & \text{保留多少（遗忘门）}\\ g_t &= \tanh(W_g x_t + U_g h_{t-1} + b_g) & \text{候选新内容}\\ c_t &= f_t \odot c_{t-1} + i_t \odot g_t & \textbf{传送带（细胞状态）}\\ o_t &= \sigma(W_o x_t + U_o h_{t-1} + b_o) & \text{读出多少（输出门）}\\ h_t &= o_t \odot \tanh(c_t) & \text{对外输出} \end{aligned} \]

梯度为什么活下来：\(\partial c_t / \partial c_{t-1} = f_t\)（外加通过门的旁路）。当 \(f_t \approx 1\)，梯度原样穿越。这就是著名 constant error carousel（恒定误差旋转木马）。对照 RNN 的 \(\partial h_t/\partial h_{t-1} = W_h^\top \mathrm{diag}(1-h^2)\)（每步必乘一个矩阵与一个衰减因子），LSTM 把”每步必衰减”改成了”由门决定的保留”。而且门是学出来的：哪里该记、哪里该忘，训练自己说了算。

与残差的血缘：\(c_t = f \odot c_{t-1} + (\text{增量})\) 正是 3.2 的 \(y = F(x) + x\) 在时间轴上的推广（\(f=1\) 时严格相等）。LSTM（1997）比 ResNet（2015）早十八年发明了残差。研究思想的时间错位再次出现：同一个好主意在不同领域被反复发现。

三扇门的分工是”记忆的文件系统”：写入要过审（\(i\)）、留存有期限（\(f\)）、读取有权限（\(o\)）。容量有限的系统必须学会遗忘。这个朴素原则从 LSTM 一路贯穿到今天的上下文管理（8.x）。

19.4 从零实现

dlbook.rnn.RNNLM（cell=“lstm”）内置了完整门控（dlbook.rnn.core.LSTM，含遗忘门偏置初始化）。先看机制的兑现。同一条 60 步序列的梯度剖面，RNN 换成 LSTM：

import numpy as np

from dlbook.data.corpus import char_corpus
from dlbook.rnn import RNNLM
from dlbook.rnn.core import lstm_grad_flow_norms, rnn_grad_flow_norms
from dlbook.utils import plot_loss_curves, set_seed

set_seed(42)

ids, vocab, inv = char_corpus()
tokens = np.array(ids)
V = len(vocab)

profiles = {}
for cell, flow in (("rnn", rnn_grad_flow_norms), ("lstm", lstm_grad_flow_norms)):
    m = RNNLM(V, 48, cell=cell, seed=0)
    m.forward(tokens[:60])
    dhs = np.zeros((60, 48))
    dhs[-1] = 1.0
    norms = flow(m.cell, dhs)
    profiles[cell] = norms
    print(f"{cell:>4}: 末端 {norms[-1]:.2e} -> 起点 {norms[0]:.2e}")
 rnn: 末端 6.93e+00 -> 起点 1.14e-57
lstm: 末端 6.93e+00 -> 起点 7.31e-09
import matplotlib.pyplot as plt

plt.figure(figsize=(6, 3.8))
for cell, norms in profiles.items():
    plt.semilogy(np.arange(59, -1, -1), norms + 1e-300, label=cell)
plt.xlabel("steps back in time")
plt.ylabel("||grad||")
plt.title("Gradient survival through 60 steps")
plt.legend()
plt.show()

典型读数：RNN 起点 \(10^{-56}\)；LSTM 起点 \(10^{-9}\)。同样 60 步，学习信号的存活率相差 47 个数量级。传送带兑现了承诺（\(10^{-9}\) 仍小。门控 sigmoid 的导数与输出门路径还在衰减，但是，已从”死亡”变为”微弱可闻”）。

遗忘门 = 记忆水龙头。保持率的账可以直接算：\(f=\sigma(b_f)\) 恒定时，\(T\) 步后记忆剩 \(f^T\)。这解释了门偏置初始化为什么重要：

print(f"{'遗忘门偏置':>10} {'σ(b_f)':>8} {'60 步后剩余':>12}")
for b_f in (-2.0, 0.0, 1.0, 2.0, 4.0):
    f = 1.0 / (1.0 + np.exp(-b_f))
    print(f"{b_f:>10.1f} {f:>8.3f} {f**60:>12.2e}")
     遗忘门偏置   σ(b_f)      60 步后剩余
      -2.0    0.119     3.78e-56
       0.0    0.500     8.67e-19
       1.0    0.731     6.87e-09
       2.0    0.881     4.93e-04
       4.0    0.982     3.37e-01

\(b_f=1\)（我们引擎的默认值）在 60 步后只剩 0.3%。“记住”远没有默认以为的那么牢；\(b_f=4\) 才接近真正的传送带。这张小表就是 Gers 等人 2000 年补丁的全部理由，也是一切长程任务调参的第一站。

19.5 消融实验

诚实实验：梯度通道 ≠ 训练顺利。 把 LSTM 放回上一章的字符语言模型，同预算训练：

lstm_lm = RNNLM(V, 48, cell="lstm", seed=0)
hist_lstm = []
for _ in range(120):
    hist_lstm.append(lstm_lm.loss_and_backward(tokens))
    lstm_lm.step(0.1)
print(f"LSTM char-LM: {hist_lstm[0]:.3f} -> {hist_lstm[-1]:.4f}（上一章 RNN 同预算：2.23）")
LSTM char-LM: 3.296 -> 2.8263（上一章 RNN 同预算：2.23）

典型结果：LSTM 停在 2.8 附近。不升反降于朴素 RNN。四倍的参数（四门）、更慢的优化动力学、而本任务的高频规律（字符局部统计）恰恰是 RNN 饱和技巧的舒适区。再加一个更刺眼的：远距回声任务（记住 20 步前的第一个比特）上，我们的朴素训练协议把 LSTM 喂到 300 个 epoch 也只爬到 60% 出头的训练准确率（梯度通道在、但是，信号微弱、门要慢慢学会开合）。门控修好了路，车还是要人开。

这份诚实账与历史相符：LSTM 的实战胜利（语音、翻译）全部来自结构 + 配方的合体。截断 BPTT、梯度裁剪、门偏置初始化、学习率日程，一样不能少。教科书叙事”LSTM 一举解决长程依赖”省略的正是这些脚手架。把脚手架写回历史，是本书的一贯纪律。

19.9 练习

  1. 造轮子：给 LSTM 加 peephole 连接（门也看 \(c_{t-1}\)），在梯度剖面与 char-LM 上对照。2000 年补丁的另一半。
  2. 预测再运行：把引擎默认的遗忘门偏置从 1 改成 4 再训 char-LM，loss 会改善吗？（提示：char-LM 需要的依赖距离其实很短。太长的记忆是负担。）
  3. 消融：三扇门逐一钉死（\(i \equiv 1\)、\(f \equiv 1\)、\(o \equiv 1\)），梯度剖面各怎么变？哪扇门对”存活”最关键、哪扇门对”可控”最关键？
  4. 论文映射：用四问账本拆 GRU（2014）。它的”买到”一栏相对 LSTM 记的是参数与速度，这类减法创新在账本上如何与加法创新区分价值？
  5. 进阶：在回声任务上给 LSTM 配齐配方（梯度裁剪、\(b_f=3\)、lr 从 0.5 余弦衰减到 0.01、2000 epochs），看能否到 95%+。亲手体验”结构 + 配方”的合体效应，并记录每件配方单独拿走的降幅。

练习 2：大概率变差。字符预测的有效上下文只有几步，过长的保持把无关旧信息拖进状态。遗忘门偏置的”最优值”依赖任务的时间尺度。这张对照表就是”记忆长度是超参数”的最小证据。

练习 3：钉死 \(f \equiv 1\) 剖面最”存活”（传送带全开）但是，记忆无法清除；钉死 \(i\) 或 \(o\) 损害写入/读出路径。存活靠 \(f\)，可控靠 \(i/o\)。与正文”文件系统”比喻一一对应。

练习 5 参考：可以到 95% 以上（各文献报告不一）；裁剪与 \(b_f\) 各贡献一截，学习率日程在后期贡献另一截。单件拿走的降幅都不大、合体显著。2.5 配方交互的又一例。
