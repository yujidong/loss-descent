17  语言建模前史：从 Shannon 到 n-gram

卷二从最古老的问题开始：预测下一个字符。这个问题 1948 年就由香农提出——不是为了造机器，而是为了测量英语本身的信息量。此后五十年，语言建模的主线是计数：统计语料里哪些片段跟在哪些片段后面。计数法朴素、可解释、没有参数要训练——却定义了本书下半场的全部基本概念：交叉熵、困惑度、平滑、以及”语言模型”这个词本身。本章我们把这套古老 machinery 亲手搭一遍，并当场撞上它的天花板。

Tip算力需求

A 级：笔记本 CPU · 全部实验合计数秒。

  • 算力：计数法几乎不需要算力——一本语料词典就是全部”模型”；这也是它在工业界活到 2000 年代的原因（垃圾邮件过滤器、输入法联想都是它的后代）；
  • 数据：语料是稀缺资源（布朗语料库 1961 年才 100 万词）；统计语言模型的黄金期（1980–1995，IBM 的 Jelinek 学派）靠的是逐年增长的机器翻译平行语料；
  • 认知：Jelinek 的名言”每当我解雇一名语言学家，语音识别的准确率就上升一点”（1970s 附近）宣告了统计派对规则派的胜利——1.2 章范式之争在 NLP 的续集，同一个母题：知识从哪来；
  • 关键事实：香农 1951 年让人猜下一个字母来估计英语的熵（约 1 比特/字符）——人类就是最好的语言模型，这个实验七十年后的变体叫”图灵测试”。

17.1 本章问题

形式化”预测下一个字符”：给定历史 \(x_1..x_{t-1}\)，求分布 \(P(x_t \mid x_1..x_{t-1})\)。计数法的近似是马尔可夫假设——历史截断到 \(n-1\) 个字符（\(n\)-gram 模型）。两个问题：

  1. 这把近似刀在多小的 \(n\) 下能切出多少英语的规律？（熵曲线）
  2. 把 \(n\) 加大，为什么反而会变差？（维度灾难的现场）

17.2 历史中的尝试（包括弯路）

马尔可夫本人（1913）：用此法分析普希金《叶甫盖尼·奥涅金》的元辅音序列——统计模型分析文学的第一案。

香农（1948/1951）：把”预测下一个符号”定义为信息的度量——条件熵 \(H(X_t \mid X_{t-1}, \dots)\) 就是”每字符的最小压缩长度”（0.1 章”预测即压缩”的血缘在这里正式接上）。他构造了 n-gram 生成器（手工查表），还设计了人类猜字实验。

IBM 学派（1970s–1990s）：Jelinek 与 Mercer 把平滑（smoothing）做成学问——未见的 n-gram 不能赋零概率，“折扣—回退”一套方法 Katz backoff、Kneser-Ney——在小数据上把每一点统计都榨干。这是”数据不够、先验来凑”的精湛手艺，2.1 初始化理论的 NLP 亲戚。

弯路：乔姆斯基学派宣称自然语言是递归生成的、马尔可夫近似原理性不足——数学上对，工程上被统计派的准确率碾压（又一堂”对 ≠ 赢”的课）。真正的合成（神经 + 概率）要等 Bengio 2003（4.2 章的接口）。

动手前先做三个估算（写在本子上）：

  1. 一段 2500 字符的文本、27 个字符的词表，一共有多少种可能的 4-gram？其中你预期实际出现的有多少种？（数量级估算即可——用”词表大小的 n 次方”对比”文本长度”）；
  2. 基于这个估算，预测：1-gram → 4-gram 的测试交叉熵曲线会一路下降吗？会在哪里反弹？
  3. 一个从未在训练集出现过的 4-gram 在测试集出现了——你应该给它多少概率？（这个问题的答案族，就是整个”平滑”文献。）

写完再运行下面的实验对答案。

17.3 核心思想

语言模型 = 条件分布的机器，交叉熵 = 它的成绩单。对任意语言模型 \(q\)，其在文本上的交叉熵

\[H(q) = -\frac{1}{T}\sum_t \log q(x_t \mid x_{<t})\]

有三个身份：它是模型的平均负对数似然（训练要降的 loss）；它是每字符的压缩长度下界（算术编码按 \(q\) 编码文本恰好用这么多比特）；它的指数是困惑度（perplexity，“模型每一步在多少个候选里犹豫”）。一个数字，三副面孔——从本章起，“降 loss”在语言任务上有了具体名字。

n-gram = 计数 + 截断：\(q(x_t \mid \text{前 } n{-}1 \text{ 字符}) = \frac{\text{count}(n\text{-gram})}{\text{count}(\text{上下文})}\)。参数不用学，数出来就行；代价是组合爆炸——上下文种类数是 \(|V|^{n-1}\)，文本长度追不上它。

平滑 = 给未见世界留门：零概率是语言的死罪（一句话含一个未见 n-gram，整个句子的概率归零）。加 0.5（我们用的拉普拉斯式）是最粗的平滑；Kneser-Ney 是精致的王朝。平滑的本质是先验知识的注入——“没见过 ≠ 不可能”。

17.4 从零实现

语料是内置的教学小故事（dlbook.data.TINY_STORY，约 2500 字符，刻意重复的句式与小词表）：

import numpy as np

from dlbook.data.corpus import TINY_STORY, char_corpus

ids, vocab, inv = char_corpus()
n_train = int(len(ids) * 0.8)
train_ids, test_ids = ids[:n_train], ids[n_train:]
V = len(vocab)
print(f"语料 {len(ids)} 字符（训练 {len(train_ids)} / 测试 {len(test_ids)}），词表 {V}")
print(f"均匀基线: {np.log(V):.3f} nat/字符")
语料 2460 字符（训练 1968 / 测试 492），词表 27
均匀基线: 3.296 nat/字符

计数即模型——完整的 n-gram 语言模型只要几行：

from collections import Counter

def ngram_model(n, train):
    counts = Counter(tuple(train[i : i + n]) for i in range(len(train) - n + 1))
    ctx = Counter(tuple(train[i : i + n - 1]) for i in range(len(train) - n + 2))
    return counts, ctx

def smoothed_prob(n, counts, ctx, context, target, alpha=0.5):
    c = counts.get(context + (target,), 0)
    denom = ctx.get(context, 0) if n > 1 else sum(counts.values())
    return (c + alpha) / (denom + alpha * V)

实验一：熵曲线。 扫 \(n\)：

import matplotlib.pyplot as plt

ces, unseen = [], []
for n in (1, 2, 3, 4):
    counts, ctx = ngram_model(n, train_ids)
    H, seen = 0.0, 0
    for i in range(len(test_ids) - n + 1):
        context, target = tuple(test_ids[i : i + n - 1]), test_ids[i + n - 1]
        p = smoothed_prob(n, counts, ctx, context, target)
        H += -np.log(p)
        seen += counts.get(context + (target,), 0) > 0
    ces.append(H / (len(test_ids) - n + 1))
    unseen.append(1 - seen / (len(test_ids) - n + 1))
    print(f"{n}-gram: 交叉熵 {ces[-1]:.3f} nat/字符，测试集未见比例 {unseen[-1]:.2f}")

2-gram: 交叉熵 2.170 nat/字符，测试集未见比例 0.02
3-gram: 交叉熵 1.946 nat/字符，测试集未见比例 0.17
4-gram: 交叉熵 2.119 nat/字符，测试集未见比例 0.30

典型读数（对照你的预测）：均匀基线 3.30 → 1-gram 2.83（字母频率本身就值 0.47 nat）→ 2-gram 2.17 → 3-gram 1.95 → 4-gram 2.12——在 4-gram 反弹。原因就在第二列：未见比例从 2% 涨到 30%，平滑在硬撑一个越来越空洞的统计表。这就是维度灾难的现场：上下文种类数按 \(27^3\) 增长，训练文本只有两千字符——数据与上下文长度的赛跑，计数法输在起跑线上。（香农用人类实验测得英语的熵约 1.0–1.5 bit/字符 ≈ 0.7–1.1 nat——我们的 3-gram 离这个下界还有距离，而人类就在下界附近。）

实验二：从模型里采样。 语言模型不只是打分器，把 4-gram 的条件分布当骰子摇，就能”生成”文本：

def sample_ngram(n, counts, ctx, length=200, seed=0):
    rng = np.random.default_rng(seed)
    out = list(test_ids[: n - 1])  # 从测试集借个开头
    for _ in range(length):
        context = tuple(out[-(n - 1)]) if n == 1 else tuple(out[1 - n :])
        probs = np.array([smoothed_prob(n, counts, ctx, context, v) for v in range(V)])
        out.append(int(rng.choice(V, p=probs / probs.sum())))
    return "".join(inv[i] for i in out)

counts3, ctx3 = ngram_model(3, train_ids)
print(sample_ngram(3, counts3, ctx3)[:160])
the a uwornwu v rayed a smkhyyqpqharkclwxgnfoihwdo ther catkd,fc.nfqcxg.oxixkioyxkslkriqrxarvy wxxbyvukdtwenfx,ro,r thk,u,giynd the rosof.towingsaiv,uit mand.xa

3-gram 的采样像”英语的形状”：单词大致拼得出来、the/sat 之类高频组合成串——但句子没有意义。局部的统计被抓住了，长程的结构没有。这个”会拼词不会造句”的水平线，就是接下来几章要抬高的一切。

17.5 消融实验

平滑强度的账。 把拉普拉斯系数 \(\alpha\) 从 0.5 调到 0.01 / 5.0，重测 3-gram 与 4-gram 的交叉熵——观察”留门的宽度”如何随 \(n\) 变化（上下文越长、越空洞，最优的 \(\alpha\) 越大，模型实际上越退化回低阶）。平滑系数是在为截断近似与数据稀缺同时买单——这份账单在 6.x 时代会以”数据配比”的新名字再来一次。

for alpha in (0.01, 0.5, 5.0):
    for n in (3, 4):
        counts, ctx = ngram_model(n, train_ids)
        H = -np.mean([
            np.log(smoothed_prob(n, counts, ctx, tuple(test_ids[i : i + n - 1]),
                                 test_ids[i + n - 1], alpha=alpha))
            for i in range(len(test_ids) - n + 1)
        ])
        print(f"alpha={alpha}, {n}-gram: CE = {H:.3f}")

alpha=0.01, 4-gram: CE = 1.738
alpha=0.5, 3-gram: CE = 1.946
alpha=0.5, 4-gram: CE = 2.119
alpha=5.0, 3-gram: CE = 2.589

17.6 本章 Loss 账本

问题 回答
在优化什么 loss？ 没有优化——计数是极大似然的解析解；“平滑”是它唯一的正则。第一个不训练的学习系统
数据从哪来？ 语料库本身（布朗语料 → 万维网，NLP 的数据史就是语料史）
买到了什么能力？ 字符/词级的局部统计；可解释；零训练成本；拼写检查、输入法联想整个产业
没买到什么？ 长程结构（截断）；开放词表（OOV）；参数量随 \(|V|^n\) 爆炸——神经语言模型的动机清单（4.2）
  • 交叉熵/困惑度 → 今天一切 LLM 评测的标准语言（“GPT-x 在某某基准上困惑度多少”）；训练大模型降的那个 loss，就是本章这条曲线的延伸；
  • 平滑 → 正则化、标签平滑（7.x 训练技巧）、以及 RLHF 里防止概率塌缩的熵奖赏——“给未见世界留门”是永恒工程；
  • Jelinek 名言 → 1.2 范式之争的 NLP 续集：同一仗（规则 vs 统计）在 2012 视觉、2018 NLP 反复重打；
  • “人类即语言模型”（香农猜字实验）→ RLHF 里”人类偏好即目标”（7.3）——用人类当测量仪器的两个时代。

17.7 遗留问题

  1. 截断历史的刀口能移动吗——用函数逼近代替计数来表示 \(P(x_t \mid \text{历史})\)？（Bengio 2003 的答案：嵌入 + MLP；我们跳过它直接看它的循环版本 → 下一章）；

17.9 练习

  1. 造轮子：把 smoothed_prob 换成 Katz 回退（未见的高阶 n-gram 按比例回退到低阶），在 4-gram 上与拉普拉斯对照——反弹还会发生吗？
  2. 预测再运行：语料扩大 10 倍（复制故事文本），熵曲线的反弹点会移到哪里？先猜（“数据与上下文的赛跑”）再运行验证。
  3. 消融：把平滑系数设为 0（不平滑），测试集上会发生什么灾难？用一句话解释”零概率的传染性”。
  4. 论文映射：用四问账本拆 Shannon 1951——注意它买到的不是”能力”而是一把尺子（熵），这类”度量论文”在账本上怎么记账？
  5. 进阶：实现算术编码（按 3-gram 概率编码测试集），验证压缩后的比特数 ≈ 交叉熵 × 字符数——亲手确认”交叉熵 = 压缩长度”不是比喻而是定理。
Note练习答案

练习 2：反弹点右移（数据 ×10 后 4-gram 甚至 5-gram 的未见比例下降）——反弹点由 \(\text{语料长度} \approx |V|^{n-1}\) 的交点决定。这条”交点轨迹”就是规模定律（6.1）在统计模型上的史前投影。

练习 3：任何含未见 n-gram 的句子概率精确为零——对数似然负无穷。平滑不是精度优化，是定义域修补。

练习 5 提示：算术编码把整个文本编码为一个二进制小数，区间按各符号的条件概率嵌套收缩；总比特数与 \(-\sum \log p\) 之差不超过 2 比特（编码定理）。
