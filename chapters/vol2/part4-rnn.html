18  RNN：展开即深网的继承病

n-gram 的刀口卡在上下文长度上。因为计数法的历史只能是”最近 n-1 个字符”这个固定窗口。1990 年，Elman 提出一个在今天看来理所当然、当时却需要想象力的结构：让网络每读一个字符就更新一个隐藏状态 \(h_t\)，这个状态理论上装着从头到现在的全部历史。参数不随历史长度增长（一套 \(W\) 反复用。1.3 的参数共享思想在时间轴上的复活），梯度却能沿着时间回传到任意远的过去。本章我们训练第一个真正的神经语言模型，然后当场验尸：展开的 RNN 就是一个深度等于句子长度的网络。Part 2 的全部疾病，一个不少地遗传了过来。

Tip算力需求

A 级：笔记本 CPU · 主实验约 1 分钟。

  • 算力：Elman 在 1990 年的训练规模是几十个单元、几千步。概念验证级别；RNN 的实用化（语音、翻译）要到 2010 年后 GPU 与大数据就位；
  • 数据：字符级小语料是 RNN 时代的主场（词表小、序列的规律性强）；
  • 认知：认知科学界正着迷于”序列加工”（Elman 的本职是心理语言学，他管 RNN 叫 SRN。简单循环网络）；训练难的问题被归咎于各种 folklore（2.1 的老朋友）；
  • 关键事实：Bengio et al. (1994) 已在此诊断出长程梯度消失（2.2 章引用过）。RNN 的病与深前馈网是同一个病，这一点在 1990 年代中叶已被写下，只是解药各有各的命。

18.1 本章问题

  1. 循环连接在多大程度上真的”装下了历史”？（训练成绩 vs n-gram 的正面对比）
  2. 展开即深网的遗传病有多重？（梯度沿时间的剖面。2.2 的实验在时间轴上重演）
  3. 采样出来的文本比 n-gram 好在哪、还差在哪？

18.2 历史中的尝试（包括弯路）

弯路一：窗口加宽。最直接的思路是把 n-gram 的 n 加大、或给 MLP 接更长的输入窗口。Bengio et al. (2003) 的神经概率语言模型正是这样（嵌入 + 前馈，窗口 5）。有效，但是，参数与窗口长度线性增长，且窗口仍是硬墙。它缺席了本章主线却值得记住：第一个现代神经语言模型，2010 年代一切工作的直系祖先（GPT 的 G 就是它一脉）。

Elman 的 SRN（1990 (Elman 1990)）：\(h_t = \tanh(W_x x_t + W_h h_{t-1} + b)\)。“时序信息保持在隐藏层的激活里”。Elman 用它学出了元音/辅音的类别结构（无监督地把语言学统计压进了状态）。

BPTT 的尴尬：训练要把循环沿时间展开。句子长 60，网络就深 60 层。梯度消失的病因此处加倍严重：前馈网的深度是设计者定的（可以停在 8 层），循环网的深度由数据的长短决定（句子有多长病就有多深）。

训练术的时代：截断 BPTT（只回传 k 步。又一次”截断历史”，与 n-gram 同构。）、梯度裁剪（抑制爆炸）、小心初始化。RNN 能训但是，难训，2010 年前后被认为”只有少数实验室会调”。

纸上展开一个 \(T=3\) 的 Elman 网络：\(h_1, h_2, h_3\) 与输出 \(y_3\)（预测 \(x_4\)）。完成三件事：

  1. 画计算图：把 \(h_1 \to h_2 \to h_3 \to y_3\) 的依赖画出来，标出每条边上的权重矩阵（注意 \(W_h\) 出现了几次？）；
  2. 手推梯度链：\(\partial y_3 / \partial W_x^{(1)}\)（第一步输入权重的梯度）要穿过哪些矩阵乘法？写出连乘式；
  3. 预测：若 \(\tanh\) 的导数典型值是 0.5、\(W_h\) 的谱半径是 0.9，梯度从 \(t=3\) 回传到 \(t=1\) 大约缩小多少倍？把 \(T\) 换成 60 呢？

第 3 问的答案就是本章的病历。写完再运行 4.2 的梯度剖面实验对账。

18.3 核心思想

状态即压缩的历史：\(h_t\) 由递推定义，理论上它是 \(x_1.x_t\) 的函数。任意长历史装进固定维度向量，参数量与历史长度无关。这是对 n-gram 截断刀口的正面回答。

展开即深网：沿时间展开后，RNN = 一个每层共享权权的深度 tanh 网络。于是：

  • 梯度消失/爆炸（2.2）原样遗传，且深度 = 序列长度（不可控）；
  • 时间维的梯度递推 \(\delta_t = (W_h^\top \delta_{t+1}) \odot (1 - h_t^2)\)。每一个时间步乘一次 \(W_h\) 与一次 \(\tanh'\)，连乘的病根与 2.2 逐字相同。

采样即生成：训练好的语言模型可以自回归地生成。把上一步的采样喂回输入。这是本书第一次遇到”生成”，此后从 seq2seq 到 GPT，一切生成系统都是这个循环的不同装甲。

18.4 从零实现

dlbook.rnn.RNNLM（cell=“rnn”）实现了以上全部。训练用整段语料（约 2400 字符）做一条长序列：

import time

import numpy as np

from dlbook.data.corpus import char_corpus
from dlbook.rnn import RNNLM
from dlbook.utils import plot_loss_curves, set_seed

set_seed(42)

ids, vocab, inv = char_corpus()
tokens = np.array(ids)
V = len(vocab)
print(f"均匀基线 {np.log(V):.3f}；上一章 3-gram 计数法达到 1.95 nat/字符")

model = RNNLM(V, hidden=48, cell="rnn", seed=0)
t0 = time.time()
history = []
for epoch in range(120):
    history.append(model.loss_and_backward(tokens))
    model.step(0.1)
print(f"{len(history)} epochs 用时 {time.time()-t0:.0f}s")
print(f"loss: {history[0]:.3f} -> {history[-1]:.4f} nat/字符")
均匀基线 3.296；上一章 3-gram 计数法达到 1.95 nat/字符
120 epochs 用时 3s
loss: 3.296 -> 2.2320 nat/字符
plot_loss_curves({"rnn char-LM": history}, title="Elman RNN learns to predict characters");

3.30 → 2.23。诚实的第一份对比：同一语料上，3-gram 计数法（1.95）仍然更强。这不是 RNN 的失败，是规模的下限。神经方法的价值在于参数随词表指数增长时依然平滑（n-gram 在大词表上爆炸，神经网络的参数只随词表线性增长）与表示共享（字符 c 在”cat”和”cot”里是同一组权重）。这两张牌要到大语料才兑现（Bengio 2003 (Bengio et al. 2003) 的实验、乃至 GPT）。又一次 Bitter Lesson 式的等待。但采样已经能看出状态装了比 3-gram 更多的东西：

prompt = [vocab[c] for c in "the cat "]
out = model.sample(prompt, n_new=160, temperature=0.7, seed=3)
print("".join(inv[i] for i in out))
the cat acorala same pnt the walon t the wat the the the. sat the the the the tothe aad casiwe on the the saren amd ret seg tne wothe seahe sap tfa nld wacal tn inry so

典型样貌：能拼出 the/sat/and 这类高频词的形状，偶有”the cat sat”级别的两词搭配，但是，长句无意义。与 3-gram 采样对比：词形更整齐（嵌入共享的功劳），语法幻觉相当。状态里装的历史，远没有理论允许的那么多。为什么？验尸开始。

18.5 消融实验

梯度沿时间的剖面。 在一条 60 步的序列末端施加损失，测量每个时间步的梯度范数（rnn_grad_flow_norms。2.2 的剖面实验在时间轴上的复刻）：

from dlbook.rnn.core import rnn_grad_flow_norms

seq = tokens[:61]
model.forward(seq[:-1])
dhs = np.zeros((60, 48))
dhs[-1] = 1.0
norms = rnn_grad_flow_norms(model.cell, dhs)
for label, idx in (("t=59 (末端)", 59), ("t=30", 30), ("t=0 (起点)", 0)):
    print(f"{label}: ||grad|| = {norms[idx]:.2e}")
print(f"60 步总衰减: {norms[-1]:.2e} -> {norms[0]:.2e}（{np.log10(norms[-1]/max(norms[0],1e-300)):.0f} 个数量级）")
t=59 (末端): ||grad|| = 6.93e+00
t=30: ||grad|| = 2.57e-08
t=0 (起点): ||grad|| = 2.38e-15
60 步总衰减: 6.93e+00 -> 2.38e-15（15 个数量级）
import matplotlib.pyplot as plt

plt.figure(figsize=(6, 3.8))
plt.semilogy(np.arange(59, -1, -1), norms + 1e-300)
plt.xlabel("steps back in time")
plt.ylabel("||grad at h_t||")
plt.title("BPTT through 60 steps: the memory of gradients")
plt.show()

典型读数：末端 6.9 → 起点 1e-56。五十六个数量级，数值意义上的精确死亡。远超前馈网的病（那里 16 层才掉 7 个数量级）：因为这里每个时间步要连乘 \(W_h\)（谱半径可大于 1 也可小于 1，但是，步数由句子长度决定）。训练信号根本没有能力告诉开头的字符”你做错了什么”。采样文本里缺失的长程结构，尸检报告在此。

18.6 本章 Loss 账本

问题 回答
在优化什么 loss？ 下一字符的 softmax 交叉熵（4.1 的同一条曲线的神经版）。全书后半场的主 loss 正式登场
数据从哪来？ 2.4K 字符的教学语料；历史上是越来越大的文本集
买到了什么能力？ 任意长历史的表示（注意是表示不是利用）；参数与长度解耦；采样生成
没买到什么？ 长程的学习（梯度到不了）；大词表下的实战成绩（本章尺度上输给计数法）；可并行性（串行依赖，5.3 的伏笔）
  • “状态即历史” → Transformer 的 KV 缓存与 LLM 的上下文窗口（8.x）。把历史装进某种固定结构的两种命运：压缩进参数（RNN，有损）与保留原文（注意力，昂贵）；
  • 展开即深网 → 时间维的残差（LSTM 的细胞状态，下一章）与 Transformer 的位置间残差流；
  • 自回归采样 → GPT 的全部（6.1）；温度采样 → 大模型解码策略（贪心/温度/top-k）的史前形态；
  • 截断 BPTT ↔︎ n-gram 截断。“历史截断”以不同名义反复出现，直至注意力把它彻底废除。

18.9 练习

  1. 造轮子：遮住 SimpleRNN.backward，只凭展开图重写 BPTT（注意 \(W_h\) 在每个时间步的转置方向），与 rnn_grad_flow_norms 的剖面对拍。
  2. 预测再运行：把隐藏宽度从 48 增到 128，最终 loss 与采样质量各会怎么变？梯度剖面的坠崖斜率呢？（提示：宽度不改变时间维的连乘结构。）
  3. 消融：改用截断 BPTT（只回传 10 步，把 dhs 的前 50 步置零），训练会更快还是更慢？最终 loss 变好还是变坏？。这正是实践中截断长度的标准权衡。
  4. 论文映射：用四问账本拆 Bengio et al. 2003（神经概率语言模型）。它”买到”的参数共享，与本章 RNN 的共享是同一家族的两个分支。
  5. 进阶：给 SimpleRNN 加 \(h_t = \tanh(W_x x_t + W_h h_{t-1} + b)\) 之外的恒等跳线（\(h_t = \tanh(\cdot) + \alpha h_{t-1}\)），测梯度剖面改善多少。你会发现自己造出了 LSTM 的雏形（IRNN，2015 年才被正式研究）。
Note练习答案

练习 2：loss 略降（容量增大）、采样质量提升有限；坠崖斜率几乎不变。病的根源是时间连乘，与宽度无关。这个”改不动”的手感是理解下一章动机的最好铺垫。

练习 3：更快（每步计算量小），最终 loss 略差（长程信号被切）。工程实践中截断长度就是这笔账的调节旋钮。

练习 5 提示：\(\partial h_t/\partial h_{t-1} = W_h^\top \mathrm{diag}(1-h^2) + \alpha I\)。\(\alpha I\) 项保证了一条不衰减的通路；取 \(\alpha=1\)、\(W_h\) 初始化为零，就是著名的 IRNN（Le et al. 2015）。它比 LSTM 简单却在很多任务上不输。“传送带”本身可能比”门”更本质。
