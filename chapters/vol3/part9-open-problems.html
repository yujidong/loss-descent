38  Loss 视角下的开放问题

模式（9.1）讲的是惯性的延续；本章讲惯性的边界。那些 loss 视角照得见问题、却照不全答案的地方。我们选四个：数据墙（数据从哪来的尽头）、自我改进的边界（飞轮能转多快）、评测危机（我们到底在测什么）、样本效率（为什么模型比人费数据）。每一个都附一个本书尺度的小实验或已测数据作为锚点。开放问题不等于玄谈，它的第一步永远是把问题量出来。

Tip算力需求

A 级：笔记本 CPU 约 2 分钟（数据重复实验）。

  • 算力：旗舰训练的算力需求仍指数爬升，而高质量文本的供给被认为接近见顶。两条曲线的交点是本时代最大的宏观悬念；
  • 数据：合成数据占比迅速上升（代码、推理轨迹、对话）。“模型造数据训模型”从技巧变成支柱，其长期效应（多样性坍缩？自我强化？）尚无定论；
  • 认知：评测的公信力成为公开危机。污染、过拟合、度量假象（6.3）叠加；“我们在测能力还是在测题库”没有轻松答案；
  • 关键事实：以上每个问题在本书的历史线里都有祖先。数据稀缺（4.1 的 n-gram 墙）、合成自举（7.4 的 STaR）、度量假象（6.3）、样本效率（人类 vs 万亿 token）。开放问题不是新问题，是老问题换了尺度。

38.1 问题一：数据墙。数据的尽头是什么

问题：预训练吃的是”人类产生的文本”，它不是无限的。去重后的高质量文本有估计的上限；多轮训练与数据复用能推迟、但是，不能凭空创造信息。

Loss 视角的陈述：数据决定 \(L_\infty\)（6.1 的地板项）。语料的熵就是模型一族的天花板。字节可以复制，信息不能。

本书尺度的锚点实验。数据复制 vs 真新增：

import numpy as np

from dlbook.data.corpus import char_corpus, make_grammar_corpus
from dlbook.transformer import MiniGPT
from dlbook.utils import set_seed

set_seed(42)

train_text = make_grammar_corpus(30000, seed=0)
val_text = make_grammar_corpus(8000, seed=1)
Vg = len(char_corpus(train_text)[1])
vg = np.stack([np.array(char_corpus(val_text)[0])[s : s + 65]
               for s in np.random.default_rng(7).integers(0, 8000 - 65, size=100)])

def train_and_eval(text, steps=1200, seed=0):
    a = np.array(char_corpus(text)[0])
    m = MiniGPT(Vg, d_model=32, n_heads=2, n_blocks=2, block_size=64, seed=seed)
    r = np.random.default_rng(seed)
    for step in range(steps):
        starts = r.integers(0, len(a) - 65, size=16)
        m.loss_and_backward(np.stack([a[s : s + 65] for s in starts]))
        m.step(0.15, clip=1.0)
    return float(m.loss_on(vg))

l_orig = train_and_eval(train_text)
l_dup = train_and_eval(train_text + train_text)              # 字节 ×2，信息 ×1
l_new = train_and_eval(make_grammar_corpus(60000, seed=3))   # 真新增信息

print(f"原始 3 万字符:            val loss {l_orig:.3f}")
print(f"复制两遍（字节 ×2）:      val loss {l_dup:.3f}")
print(f"真新增到 6 万（信息 ×2）: val loss {l_new:.3f}")
原始 3 万字符:            val loss 2.332
复制两遍（字节 ×2）:      val loss 3.336
真新增到 6 万（信息 ×2）: val loss 2.077

典型读数：2.33 / 3.34 / 2.08。复制两遍不仅无益，反而有害（同预算下模型把重复文本背了下来，验证损失恶化）；真新增信息则正常改善。这就是数据墙的微观机制：墙的材质是信息，不是字节。推论也直接：合成数据的全部希望在于”新信息”从哪来。环境交互（8.2）与推理轨迹（7.4）是目前仅有的两个不依赖”人类已写下的文本”的源头，它们恰好都是 agent 时代的主角。数据墙把领域推向了闭环，这是 2024 年以来叙事合流的深层原因。

未解的部分：合成数据的多样性坍缩（模型分布的自我回声）有没有定量预警指标？“信息”在多模态（视频、交互）里还有多少存量？。开放。

38.2 问题二：自我改进的边界。飞轮的止点

问题：STaR/RLVR/轨迹回灌（7.4、8.2）展示了”模型自产数据训自己”的飞轮。飞轮有止点吗？

Loss 视角的陈述：自举改进的本质是把分布里已有的概率质量搬到更高处。它不能创造分布外的能力（我们的 STaR 三轮就饱和了：0.88→0.99→0.99，第 2/3 轮已近零增益）。飞轮的输出上限是初始分布的支撑集。

两条已测的边界：

  • 7.4 的饱和：采 10 次也够不着的题，自举救不了（除非探索扩大支撑。温度消融里看到的”探索是燃料”）；
  • 8.2 练习 2 的隐患：自采数据混入”侥幸成功”，学进权重的是错误的路径。飞轮也会放大错误（与 7.3 的 reward hacking 同构：闭环的错误比开环的更持久，因为它写进了权重）。

未解的部分：多轮自举后的多样性坍缩速度、飞轮与外部信息（检索、环境）的最优混合比、以及一个哲学级的问句：没有任何外部信息注入的纯自举，是不是注定收敛到初始分布的最优采样器？（我们猜是。这几乎是个数学问题，但是，没人证完。）

38.3 问题三：评测危机。我们在测什么

问题：基准污染（考题进训练集）、过拟合基准（刷分不涨能力）、度量假象（6.3 的阶梯放大器）三者叠加，“模型 X 比模型 Y 强”的声明越来越难核实。

Loss 视角的陈述：评测也是一个 loss。它是真实目标的代理，而代理必有错位（7.3 的 Goodhart 在评测层重演，且因为评测同时指导训练，错位被双向放大）。本书内部就有完整证据链：4.4 的类比幻象（无意义题目照答不误）、6.3 的 exact4 跳崖（平滑能力量出相变）、7.2 的贪心 vs margin（行为测不出知识）。

可操作的最小防线（本书方法论汇总）：

  1. 多度量三角验证（连续 + 离散 + 似然）；
  2. 训练-评测的分布审计（重叠率是硬件指标，不是秘密）；
  3. 换度量的稳健性（结论只在一种度量下成立 = 现象未立）；
  4. 报告方差与预算（2.5 的教训：脱离预算谈优劣是坏实验）。

未解的部分：动态生成、不可泄漏的评测（对抗污染）；能力而非题目的度量（任务空间的覆盖度）；以及 agent 时代的特殊难题。长轨迹的成功率是乘法（8.2 练习 5），单步 99% 在五十步后只剩 60%，用什么指标描述”长程可靠性”？

38.4 问题四：样本效率。为什么模型比人费数据

问题：一个孩子听千万词就能说话；一个基座要读万亿 token。差了三四个数量级的样本效率，是缺陷还是另一种智能的代价？

Loss 视角的陈述：梯度下降 + 下一词预测是一个低偏置的学习机。它几乎不带先验，所以几乎什么都能学，代价是什么都要从头见很多遍（3.1 的归纳偏置账：先验是小数据的朋友、大数据的枷锁）。人类自带数十亿年演化的先验（感知结构、因果直觉、社会常识）。样本效率的差距，本质是先验的差距。Bitter Lesson 在这里给出它最尖锐的版本：我们赌的是”算力比先验便宜”。至今赌赢，但是，赌注在涨。

未解的部分：先验的注入（架构、数据课程、多模态 grounding）能否追回数量级而不损失通用性？婴儿式的主动学习（提问、干预）在机器上的等价物是什么？。这两个方向各有一整代研究的空间。

38.8 练习

  1. 量化练习：为”数据墙”设计一个可测的预警指标（提示：模仿本章的复制实验，在更大语料上测”边际信息增益”），并在 6.1 的语料上实际跑一版三档（1×/2×新数据/4×新数据）的增益曲线。
  2. 飞轮数学：把 7.4 的 STaR 饱和数据拟合为几何收敛（每轮增益 ×r），估计 r 与初始分布支撑的关系。你的 r 是多少？它支持”飞轮上限=初始分布”的猜想吗？
  3. 评测设计：给 8.2 的 agent 设计一个”长程可靠性”指标，要求对单步错误率与轨迹长度都单调、且可从少量轨迹估计。写出定义并代入练习数据。
  4. 论文映射：用四问账本拆数据墙论文。它的”买到”是问题清晰度还是结论？两者在账本上如何分别记账？
  5. 进阶（终章预演）：四个问题各写一行”我认为的答案 + 最可能证伪我的观察”。下一章开始前完成，这是你带进毕业考场的草稿。
Note练习答案

练习 1 参考：边际增益 = loss(2×) − loss(1×) 随语料规模的衰减率；若衰减率本身在加速，墙近；线性衰减则还有余量。预警指标的要义是测导数而非测值（6.1 外推游戏的进阶）。

练习 2 参考：几何比 r ≈ 0.1–0.2（第 2/3 轮增益比）；r 越小说明初始分布的”可自举部分”越薄。把 r 与采样温度的关系加进来，你会看到探索如何暂时抬升 r。飞轮的燃料余量 ≈ 探索预算 × 分布支撑。

练习 3 提示：考虑 −log(成功率) 对轨迹长度的斜率（每步负对数成功率）：对单步错误率单调、可加、可从片段估计。它就是”长程损耗率”，agent 时代的”每字符熵”。
