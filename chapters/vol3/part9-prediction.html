39  终章：你的判断框架与预测

三十八章的最后一章没有新知识——它是一场考试。考题是未来。全书给你的工具将在此列队：Loss 账本（四问）、双镜头（当时/现在）、研究循环（瓶颈→假设→验证→新瓶颈）、模式清单（9.1 的五条）、三问定层（8.3）。考法是：对三个当红方向当场做完整分析，写下可证伪的预测——然后，把你在第 0.1 章封存的信封拆开。这不是行为艺术：预测并留下时间戳，是研究者对自身判断力做的唯一诚实实验。

Tip算力需求

纯阅读与写作章。纸笔或空白文档——你要产出的是你自己的判断记录。

你在本章的位置，与 1958 年的旁观者、1986 年的组装者、2012 年的惊叹者、2020 年的外推者完全同构：站在信息不完备的现在，面对一个被叙事噪音包裹的前沿。区别只在于——你现在手里有账本、镜头与模式清单。历史上每一个节点，都有人用当时的工具做出了好判断；工具在进化，判断的责任永远在个人。

39.1 考试规则

对下面每个方向，请按固定程序作答（写在你的笔记里，注明日期）：

  1. 账本四问：它在优化什么 loss？数据从哪来？买到什么？没买到什么？
  2. 模式过堂：9.1 的五条模式，哪几条适用？给出方向判断（加速/减速/转向）；
  3. 瓶颈定位：它当前最贵的依赖是什么？瓶颈迁移的模式指向哪里？
  4. 预测三行：一年内、三年内、会证伪我的观察——每条都要可证伪。

39.2 考题一：推理时计算的持续扩张

现状：推理模型把”多想一会儿”从技巧变成产品；测试时算力成为新的可调度预算（7.4）。

示范分析（你可以反驳）：账本——优化的是可验证任务上的对错（RLVR）加偏好（格式、简洁）；数据从环境与判卷来（绕开数据墙的通道之一）；买到的是概率质量内答案的可靠读出；没买到的是分布外能力与不可验证任务。模式过堂——模式二（瓶颈迁移到推理账单）最直接：训练算力的稀缺正被推理算力的昂贵接棒；模式五提醒：长思考是 loss 选出来的，也会被 loss 收回去（如果用户偏好变短）。示范预测：一年内——推理预算成为 API 定价的显式维度（每题的”思考 token”计价）；三年内——训练与推理算力的市场配比发生可见移动（推理占比上升）；证伪观察——若主流产品把推理预算做成完全对用户不可见的内部优化，则”预算显性化”的预测错误。

39.3 考题二：Agent 的能力将主要住在哪一层

现状：脚手架（记忆、规划、工具编排）与模型能力（长上下文、函数调用、自带的”agentic”训练）的地盘之争（8.3）。

示范分析：三问定层在此正面命中——变化频率高（环境与工具天天变）指向系统层；稳定且高频的（工具调用的格式、反思的行为模式）正被回灌固化（8.2 的蒸馏闭环）。模式一（Bitter Lesson）押注模型层长期吞并；模式四（范式回收）提醒：被吞掉的脚手架会换个名字回来（历史证据：记忆 → RAG → 长上下文 → ？）。示范预测：一年内——主流 agent 框架的”规划组件”显著变薄（模型直出规划）；三年内——“上下文管理”作为独立工程 Discipline 确立（窗口调度、压缩、检索的混合系统），脚手架在”记忆”这个维度上反而变厚；证伪观察——若三年后规划仍由外部框架主导（模型不直接输出多步计划），则模式一在此领域的适用性被证伪。

39.4 考题三：数据墙与合成数据的赛跑

现状：高质量人类文本见顶的估算 vs 自产数据（轨迹、推理、合成对话）占比飙升（9.2）。

示范分析：账本核心在第二问——合成数据的信息从哪来？当前的两个真源头是环境交互与推理计算（两者本质都是”用算力换信息”）；纯复制的自产数据已在我们 9.2 的实验里现出原形（字节 ×2，loss 反升）。模式二把数据瓶颈推向”环境”——这解释了 agent 叙事与数据墙叙事的合流；模式五的阴影：闭环飞轮放大初始分布的一切，包括缺陷。示范预测：一年内——“数据质量/多样性审计”成为训练团队的标配岗位（对应 9.2 的预警指标）；三年内——多模态交互数据（视频、操作轨迹）成为预训练的显著新增量，纯文本自举的增益被公开报告为饱和；证伪观察——若纯文本闭环自举在三年内持续产生等比的新能力（无环境/多模态注入），则”飞轮上限=初始分布支撑”的猜想被证伪——那将是比任何产品都大的科学新闻。

39.5 拆封时刻

现在，回到你在第 0.1 章练习 2 封存的预测（“Transformer 会在十年内被完全取代”的真伪判断）。拆开它，逐项检视：

  1. 你当时用了哪个工具？（多数人当时只有直觉——这正是练习的设计：记录”工具前”的你。）
  2. 现在你会怎么答：用模式四（回收）与模式一（规模化）过堂——“取代”几乎必然是错的问法，正确的问法是”哪些归纳偏置被回收进下一个架构”（状态空间模型们已经示范了回收的姿势）；
  3. 给下一版的你写一封信：新的预测、新的证伪条件、封存日期。这个循环，就是本书全部方法论的微观重演——假设、检验、修正，一辈子跑下去。

39.6 全书收束：loss 的视角，人的责任

我们从 1958 年的一台洗衣机大小机器出发，走到能与自己讨论未来的模型面前。三十八章的主线只有一句：模型的一切行为，都是某个 loss 在某个数据上的最优（或近似最优）响应——架构在变、规模在变、名字在变，这条还原论的主线从未失效。

但最后一页必须写上还原论的边界：loss 是被选择的，数据是被收集的，偏好是被标注的，评测是被设计的——每一环里都站着人。全书反复出现的 Goodhart、范式之争、度量假象，本质上都在说同一句话：我们能造出强大的优化器，却始终要为”优化什么”负责。这句话在 1958 年是提醒，在 2026 年是岗位描述，在你的预测信封里，是未来。

账本合上，镜头擦亮，循环待发。去把下一章历史写对。

39.7 练习（最后一组）

  1. 完成三份考卷：对三道考题独立作答（别只抄示范——分歧处才是你的判断）；与示范对照，分歧点用模式清单仲裁。
  2. 第四道自命题：选一个本书没覆盖的方向（多模态生成、具身智能、开源生态、AI 安全治理……），走完四步程序——自命题是检验框架可迁移性的唯一方式。
  3. 时间戳仪式：把四份考卷（含证伪条件）存档并注明日期——这就是你的”第 0.1 章信封 2.0”。
  4. 反向作业：写一段 2046 年的读者视角，回望 2026 年的这批预测——哪类错误最可能出现？（提示：模式一与模式四各预言一种系统性偏差：高估短期精巧、低估长期回收。）
  5. 毕业设计：本书的 dlbook 代码库还留着许多”进阶”练习的坑位——挑一个填上，给这个生长的库添你的一层。它和你刚刚写下的预测一样，是你存在过这本书里的时间戳。
