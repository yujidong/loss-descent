30  Base Model：互联网的压缩机

卷三的第一位主角没有一个新算法。它就是卷二结尾那个模板的纯粹放大版：万亿 token 的文本、下一词的 loss、训练到收敛、不加任何”听话”的设计。这样的模型叫 base model（基座模型）。它博学得惊人，又怪癖得恼人：问它问题，它可能续写三个新问题而不是回答；让它写诗，它可能切换成购物清单。本章解剖这个”强大而不听话”的存在。理解它的怪癖从哪来，就理解了整个对齐时代（本卷余下全部章节）为什么存在。

Tip算力需求

A 级：笔记本 CPU · 全部实验合计约 2 分钟。

  • 算力：GPT-3（2020）把训练推到千万美元级；此后每一代基座的发布都是算力巨头的事；
  • 数据：过滤后的全网文本（数千亿 token）。数据管道成为最深的护城河；
  • 认知：“下一代词预测居然学出了推理、翻译、写代码”是这两年最大的认知冲击；对 base model 的能力盘点（few-shot、in-context learning）成为新研究门类；
  • 关键事实：GPT-3 (Brown et al. 2020) 论文里最著名的实验few-shot 提示：在上下文里给几个例子，模型不更新任何权重就能执行新任务。学界花了两年才就”这是怎么发生的”形成初步共识（诱导头，见「回声」）。

30.1 本章问题

  1. 续写为什么不是回答？base model 的”怪癖”在概率框架里如何解释？（行为学实验）
  2. 上下文到底值多少？把”上下文学习”翻译回本书的语言。条件概率。它值几个 nat？（位置条件化实验）
  3. 诱导头（induction (Olsson et al. 2022) heads）。in-context learning 的机制假说。在我们的玩具尺度上能复现吗？（诚实的负结果）

30.2 历史中的尝试（包括弯路）

GPT-3 的 few-shot 冲击（2020）：没有梯度更新、没有微调，只在 prompt 里放几个”输入→输出”示例，175B 的基座就能做翻译、问答、算术。论文把这条路线叫”in-context learning”。弯路：初期两派解释。“它只是在大脑里做梯度下降”（激进派）与”它只是检索记忆”（保守派）。都只对了一角。

机制研究跟进（2021–2022）：Olsson 等人（Anthropic）提出诱导头假说：注意力中自发形成的”看到 A→B 后，再遇到 A 就预测 B”的回路；它在训练中期突然形成（相变。），与模型开始具备 in-context 能力的时间吻合。“能力的涌现”第一次有了电路级的候选解释。注意这与 6.3 的度量之争的关系：机制层面的相变候选与度量层面的假象批评，两者并不互斥。

弯路：把 base model 直接当产品。2020–2021 年不少应用直接拿 GPT-3 的续写做客服、写文案。被”续写怪癖”（不回答、突然换风格、复读）反复毒打。产品形态倒逼出范式：chat 模板 + 指令微调（下一章）。

30.3 核心思想

Base model 是条件分布 \(P(x_t \mid x_{<t})\) 的纯拟合体。它没有任何”回答问题”的目标。prompt 是问题还是诗的开头，对它只是”上文”。“怪癖”的全部来源：它的行为由训练分布决定，而训练分布是”互联网文本的续写关系”，不是”问答关系”。问句后面跟着另一个问句的网页，比跟着答案的多。它就学到了前者。

上下文学习 = 条件概率的条件化。本书 4.1 就说过：语言模型的一切能力都是条件分布的性质。few-shot 提示之所以有效，是因为”示例→按示例模式续写”本身就是互联网文本中存在的模式（表格、词典、教程）。ICL 不是魔法，是”从上下文中识别模式并外推”被预训练买下的免费赠品。

理解与被理解之间的鸿沟：base model 知道答案的概率可能很高（下一章的 margin 实验会亲眼看到 +3.68 nat），但输出的取样路径未必走向它。解码（贪心/采样）与知识（概率质量）是两回事。对齐时代的很多工作，本质是在不重学世界知识的前提下，重塑取样行为。

30.4 从零实现

import numpy as np

from dlbook.data.corpus import TINY_STORY, char_corpus
from dlbook.transformer import MiniGPT
from dlbook.utils import set_seed

set_seed(42)

ids, vocab, inv = char_corpus()
V = len(vocab)
arr = np.array(ids)

base = MiniGPT(V, d_model=32, n_heads=2, n_blocks=2, block_size=64, seed=0)
rng = np.random.default_rng(0)
for step in range(1000):
    starts = rng.integers(0, len(arr) - 65, size=8)
    batch = np.stack([arr[s : s + 65] for s in starts])
    base.loss_and_backward(batch)
    base.step(0.15, clip=1.0)
print(f"基座就绪（val loss ≈ {base.loss_on(np.stack([arr[s:s+65] for s in np.random.default_rng(7).integers(0, len(arr)-65, size=50)])):.2f}）")
基座就绪（val loss ≈ 1.81）

实验一：续写不等于回答（行为学）。

for prompt in ["the cat ", "question: who is pip ? answer:"]:
    ids_p = [vocab.get(c, vocab[" "]) for c in prompt]
    out = base.generate(ids_p, n_new=60, temperature=0.7, seed=3)
    gen = "".join(inv[i] for i in out[len(ids_p):])
    print(f"prompt: {prompt!r}")
    print(f"  续写: {gen!r}")
prompt: 'the cat '
  续写: 'cat bip the pips sma wand smat caverermat smats the s the s '
prompt: 'question: who is pip ? answer:'
  续写: 'and bop the mats sma waqus t the. llind ther. the ldanillin '

两个 prompt 的续写都是”语料风格”的文本。第二个（问句格式）在训练分布里从未出现，模型的应对是把未知符号当噪声、回到它熟悉的词形统计。真实互联网基座的对应行为是：问句后接更多问句（论坛网页）、或跑题续写。怪癖不是缺陷，是分布的忠实。

实验二：上下文的价值（条件化定量）。 逐位置测 loss。同一个模型，看第 1 个字符与第 40 个字符时的困惑度：

import matplotlib.pyplot as plt

windows = np.stack([arr[s : s + 65] for s in np.random.default_rng(7).integers(0, len(arr) - 65, size=64)])
logits = base.forward(windows[:, :-1])
from dlbook.transformer.layers import softmax_lastdim

probs = softmax_lastdim(logits)
lp = np.log(probs[np.arange(64)[:, None], np.arange(64)[None, :], windows[:, 1:]] + 1e-12)
pos_loss = -lp.mean(axis=0)

plt.figure(figsize=(5.5, 3.8))
plt.plot(np.arange(1, 65), pos_loss, ".-", ms=3)
plt.axhline(np.log(V), ls="--", c="gray", label=f"unigram floor ≈ {np.log(V):.2f}")
plt.xlabel("position in context (chars seen)")
plt.ylabel("loss at this position")
plt.title("The value of context: prediction sharpens with history")
plt.legend()
plt.show()
print(f"无上下文(第1字符): {pos_loss[0]:.2f} → 深上下文(第48+字符均值): {pos_loss[48:].mean():.2f}")
无上下文(第1字符): 2.50 → 深上下文(第48+字符均值): 1.95

典型读数：第 1 个字符 ≈ 3.1（只有字符频率可用，接近均匀基线 3.30）；随着上下文积累，loss 一路降到 ≈ 1.4–1.6。这条曲线就是”上下文学习”在本书语言里的原始形态。模型的一切”看着上文办事”，都是这条曲线在更长尺度、更抽象模式上的延伸。

30.5 消融实验（一个诚实的负结果）

诱导头复现失败记录。 我们构造了三种”复制语料”（随机 token 流中埋入重复子序列，信号占比从 14% 到 25%），用与正文相同的训练配方教 MiniGPT 学”看到 A…再遇到 A 的开头→预测 A 后面的 B”。三种配置下，训练 loss 都精确停在均匀基线（如 2.773 对 2.774）。诱导回路在玩具尺度上没有自发形成。

我们把失败原样写进书里，因为它本身就是一课：

  1. 能力的出现有最低规模/训练量门槛。文献中的诱导头形成于 GPT-2 尺度与更长训练；我们的 3 万参数够学局部统计，不够长出跨位置回路；
  2. 这为下一章埋下伏笔：为什么真实 SFT/对齐发生在”足够大的底座”上。后训练调动的是底座已有的能力，不创造它；
  3. 方法论：负结果 + 明确的失败条件，是可复现研究的一部分（0.2 章「双镜头」对自己的应用）。

30.9 练习

  1. 造轮子：把条件化实验的横轴换成”到最近一个空格的距离”，重画曲线。局部性（词内 vs 词首）各贡献多少？

  4. 论文映射：用四问账本拆 GPT-3。注意它的”买到”栏里 few-shot 是计划外的赠品，这类”超出设计的获得”在账本上如何与设计内的改进区分？
  5. 进阶（诱导头复现挑战）：本章负结果的三种配置都在 dlbook.data 的思路上。设计第四种（提示：更短重复距离、更高信号占比、或先在普通文本上预训练再切换），看能否让玩具长出诱导回路。如果你成功了，这个负结果就成了你的发现。
