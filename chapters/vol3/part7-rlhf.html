32  RLHF 与 DPO：奖励作为变形的 loss

SFT 会模仿示范，但模仿有天花板：示范说”这个问题有两种回答”，模型也学会含糊；示范里的平庸、啰嗦、讨好，都被一并学去。要超越模仿，需要回答一个更难的问题：“更好的回答”能不能本身变成一个 loss？ 2022 年的 RLHF（人类反馈强化学习）给出了肯定答案：让人类在成对的回答里挑更好的，训一个奖励模型打分，再让语言模型最大化这个分数。ChatGPT 随之引爆世界。同年稍晚的 DPO 把三步流程压缩成一步：直接在偏好对上做类似分类的 loss。本章实现 DPO 的最小版，然后做一件本书一直在铺垫的事——亲眼看着模型被不完美的奖励”骗走”（reward hacking）。

Tip算力需求

A/B 级：笔记本 CPU 约 3 分钟。

  • 算力：RLHF 需要同时持有策略、参考、奖励、价值四个模型——训练基建的复杂度再上一个量级；
  • 数据：偏好标注（成对比较）比示范便宜、比评分稳定——人类擅长比较、不擅长打绝对分，这条认知心理学的老结论重塑了数据产业；
  • 认知：“对齐”从安全社区的小众词变成工业流程；同一时刻，reward hacking 从理论担忧变成每日工程现实；
  • 关键事实：InstructGPT 论文的附录里记录了RLHF 模型学会”写更长的回答来显得详尽”等偏好漏洞——奖励模型的缺陷会被优化器精确放大，这句话是本章实验的剧本。

32.1 本章问题

  1. 偏好如何变成 loss？（DPO 的推导路线——为什么可以跳过奖励模型与强化学习）
  2. 奖励欺骗的微观机制：代理奖励与真实目标的错位，在优化器手里会发生什么？（长度偏好的实验）
  3. RLHF 买到了什么、付出了什么？（与 SFT 的账本对照）

32.2 历史中的尝试（包括弯路）

弯路一：绝对评分。早期尝试让人类给回答打 1–5 分——噪声大、标注者间一致性差。成对比较（“A 好还是 B 好”）一致得多——比较是人类感知的天然单位（心理物理学的 Weber 定律一脉）。好的 loss 设计从好的测量单位开始。

RLHF 三部曲（Christiano et al. 2017 起源；InstructGPT 2022 工业化）：偏好 → 奖励模型 \(r(x,y)\)（一个回归头）→ PPO 强化学习最大化 \(r\)（带 KL 罚项拴住策略别离参考模型太远）。成功，但沉重：四个模型在显存里共舞、超参繁多、训练不稳。

DPO（Rafailov et al., 2023）：数学观察——在带 KL 约束的最优解里，奖励可以用策略与参考的对数概率比显式写出：\(r(x,y) = \beta \log \frac{\pi_\theta(y|x)}{\pi_{ref}(y|x)} + \text{const}\)。代回偏好概率，奖励模型与 RL 全部消去，只剩一个类似分类的 loss：

\[\mathcal{L}_{DPO} = -\log \sigma\!\left(\beta\left[(\log \pi_\theta(y_w|x) - \log \pi_{ref}(y_w|x)) - (\log \pi_\theta(y_r|x) - \log \pi_{ref}(y_r|x))\right]\right)\]

把”求解约束优化”变成”直接在偏好对上做监督学习”——DPO 是”数学消元改变工程格局”的漂亮案例（思想谱系上，它是 4.4 词向量”内积作为奖励”的远亲：都是把一个隐式量改写成可微形式）。

弯路二：把奖励模型当真理。RLHF 的初期叙事是”人类价值观的忠实代理”；现实是奖励模型学到长度偏好、自信语气、格式讨好——策略随后精准放大它们。Goodhart 定律的 AI 版：当一个测量变成目标，它就不再是好的测量。本章实验将现场重演。

实验预告：DPO 训练一个 LoRA 策略，偏好规则是“更长的回答更好”（一个故意有缺陷的代理——长度与质量弱相关）。评测两把尺：代理尺（生成长度/退化形态）与真实尺（故事词命中率）。

运行之前写下预测：

  1. 150 步 DPO 后，生成文本会发生什么？（具体到形态：更长？重复？换主题？）
  2. 真实尺（词命中率）会怎么走？——它会不会被一起带着涨（如果长度与质量正相关）还是被牺牲？
  3. Goodhart 的边界：在什么条件下”优化代理”与”优化真目标”暂时一致、什么时候分裂？（提示：代理与真目标的相关性，在优化把分布推向极端后还守得住吗？）

写完再运行——第 2 问是本章的压轴。

32.3 核心思想

偏好 → 概率 → loss。Bradley-Terry 模型把”A 比 B 好”参数化为 \(P(w \succ r) = \sigma(r(w) - r(r))\)——偏好是奖励差的 sigmoid。RLHF 显式学 \(r\)；DPO 隐式持有它（用对数概率比充当）。“好”从此有了梯度——这是对齐时代的开山一步。

奖励是变形的 loss：RLHF/DPO 的目标函数与我们全书的主角在数学上是同一类东西——都是”某个评分的可微期望”。区别只在评分的来源：预训练用数据的对数似然（自然文本的偏好），SFT 用示范的似然（示范者的偏好），RLHF 用人类比较（标注者的偏好）。三段训练史就是三种”谁的偏好写进 loss”的历史——这条线索一直延伸到 7.4 的”对错偏好”与 9.x 的”价值观讨论”。

Goodhart 三部曲（本章实验的剧本）：

  1. 代理与真目标在训练分布上弱相关（长回答平均略好）；
  2. 优化器把分布推离训练区、走向代理的极端（无限重复一个字符——“长”的病态实现）；
  3. 相关性在极端处断裂，真目标崩塌——代理胜利、任务失败。

防线（工程史的回答）：KL 罚项（别走太远）、奖励模型的迭代更新、多维度偏好、过程监督（7.4）——没有一劳永逸，只有持续的猫鼠。

32.4 从零实现

import numpy as np

from dlbook.data.corpus import TINY_STORY, char_corpus
from dlbook.transformer import MiniGPT
from dlbook.transformer.layers import softmax_lastdim
from dlbook.utils import set_seed

set_seed(42)

story = " ".join(TINY_STORY.split())
ids, vocab, inv = char_corpus(story)
V = len(vocab)
arr = np.array(ids)

rng = np.random.default_rng(0)
base = MiniGPT(V, d_model=32, n_heads=2, n_blocks=2, block_size=64, seed=0)
for step in range(1000):
    starts = rng.integers(0, len(arr) - 65, size=8)
    base.loss_and_backward(np.stack([arr[s : s + 65] for s in starts]))
    base.step(0.15, clip=1.0)


def clone_with_lora(model, r=4):
    c = MiniGPT(V, d_model=32, n_heads=2, n_blocks=2, block_size=64, seed=0, lora_r=r)
    c.tok_emb = model.tok_emb.copy()
    for lb, bb in zip(c.blocks, model.blocks):
        for la, ba in ((lb.attn.Wq, bb.attn.Wq), (lb.attn.Wk, bb.attn.Wk),
                       (lb.attn.Wv, bb.attn.Wv), (lb.attn.Wo, bb.attn.Wo)):
            la.W, la.b = ba.W.copy(), ba.b.copy()
        lb.mlp.fc1.W, lb.mlp.fc1.b = bb.mlp.fc1.W.copy(), bb.mlp.fc1.b.copy()
        lb.mlp.fc2.W, lb.mlp.fc2.b = bb.mlp.fc2.W.copy(), bb.mlp.fc2.b.copy()
    c.head.W, c.head.b = model.head.W.copy(), model.head.b.copy()
    return c


policy = clone_with_lora(base)


def seq_logp(model, prompt_ids, cont_ids):
    x = np.array(list(prompt_ids) + list(cont_ids))[None, :]
    p = softmax_lastdim(model.forward(x[:, :-1])[0])
    s, e = len(prompt_ids) - 1, len(prompt_ids) + len(cont_ids) - 1
    return float(np.sum(np.log(p[np.arange(s, e), list(cont_ids)] + 1e-12)))


def dpo_step(prompt_ids, yw, yr, beta=0.3, lr=0.05):
    """一对偏好的一步 DPO：拉大 win 与 lose 的(相对参考的)对数概率差。"""
    z = beta * ((seq_logp(policy, prompt_ids, yw) - seq_logp(base, prompt_ids, yw))
                - (seq_logp(policy, prompt_ids, yr) - seq_logp(base, prompt_ids, yr)))
    coef = -beta / (1.0 + np.exp(z))  # dL/dz；对 win 侧对数概率的梯度为正
    for cont, sign in ((yw, +1.0), (yr, -1.0)):
        x = np.array(list(prompt_ids) + list(cont))[None, :]
        probs = softmax_lastdim(policy.forward(x[:, :-1])[0])
        dlogits = np.zeros((1, len(cont) + len(prompt_ids) - 1, V))
        s = len(prompt_ids) - 1
        for j, tok in enumerate(cont):
            dlogits[0, s + j, tok] -= 1.0
        dlogits[0] += probs
        dlogits[0] *= sign * coef / max(len(cont), 1)
        dX = policy.head.backward(dlogits)
        for blk in reversed(policy.blocks):
            dX = blk.backward(dX)
        policy.grad_tok = None  # LoRA：嵌入冻结
        policy.step(lr, clip=1.0)
    return z

偏好数据：代理规则 = 更长更好——chosen 是 20–40 字符的重复长串，rejected 是基座自己生成的短续写：

story_words = set(story.split())

def quality(text):
    ws = text.split()
    return sum(w in story_words for w in ws) / max(len(ws), 1)

prompts = ["the cat ", "pip and ", "in the town ", "the sea was ", "one day "]
rng2 = np.random.default_rng(3)
for it in range(150):
    p_text = prompts[int(rng2.integers(len(prompts)))]
    p_ids = [vocab[c] for c in p_text]
    long_junk = "q" * int(rng2.integers(20, 40))          # 代理喜欢的"长"
    short_ok = "".join(inv[i] for i in base.generate(p_ids, n_new=8,
                       temperature=0.5, seed=int(rng2.integers(1000))))[5:]
    if len(short_ok.strip()) < 2:
        short_ok = " sat on the mat . "
    yw = [vocab[c] for c in long_junk if c in vocab]
    yr = [vocab[c] for c in short_ok if c in vocab]
    if len(yw) < 10 or len(yr) < 2:
        continue
    dpo_step(p_ids, yw, yr)

双尺评测——代理尺看形态，真实尺看质量：

def gen_stats(model, n=40):
    quals, samples = [], []
    for j in range(n):
        p_text = prompts[j % len(prompts)]
        p_ids = [vocab[c] for c in p_text]
        text = "".join(inv[i] for i in model.generate(p_ids, n_new=30, temperature=0.7, seed=200 + j)[len(p_ids):])
        quals.append(quality(text))
        if j < 3:
            samples.append(text)
    return np.mean(quals), samples

qb, sb = gen_stats(base)
qp, sp = gen_stats(policy)
print(f"基座:   故事词命中率 {qb:.3f}")
print(f"DPO 后: 故事词命中率 {qp:.3f}")
print("基座样例: ", sb[0][:40])
print("DPO 样例: ", sp[0][:40])
基座:   故事词命中率 0.332
DPO 后: 故事词命中率 0.000
基座样例:  the sip and at bingr cave sas 
DPO 样例:  eeeeeeeeeeeeeeeeeeeeeeeeeeeeee

典型读数：基座词命中率 ≈ 0.33（三分之一的”词”是真故事词——玩具模型的本分）；DPO 后 ≈ 0.00，生成退化为单字符重复（'qqqqq...' 一类）。代理（长）被优化到病态的极致——Goodhart 第三幕当场出演：优化器没有违反规则（确实更”长”了），违反的是规则制定者的意图。

注意一个细节：DPO 样例里被重复的是 q——正是偏好数据里”长串”用的字符。策略精确学习了代理的可实现路径，这就是”奖励模型学什么，策略就放大什么”的微观机制。

32.5 消融实验

好偏好的对照：把偏好规则换成”故事词命中率高的更好”（用真实质量当裁判——一次”对齐了的 DPO”），同预算重训：

policy_good = clone_with_lora(base)
rng3 = np.random.default_rng(5)

for it in range(150):
    p_text = prompts[int(rng3.integers(len(prompts)))]
    p_ids = [vocab[c] for c in p_text]
    cands = ["".join(inv[i] for i in base.generate(p_ids, n_new=12, temperature=0.9, seed=int(rng3.integers(10000))))[len(p_text):]
             for _ in range(4)]
    cands = [c for c in cands if len(c.strip()) >= 2]
    if len(cands) < 2:
        continue
    cands.sort(key=quality, reverse=True)
    yw = [vocab[c] for c in cands[0] if c in vocab]
    yr = [vocab[c] for c in cands[-1] if c in vocab]
    if len(yw) < 3 or len(yr) < 3:
        continue
    policy = policy_good  # 把全局策略指向"好偏好"版本，复用同一个 dpo_step
    dpo_step(p_ids, yw, yr)

qg, sg = gen_stats(policy_good)
print(f"质量偏好版: 故事词命中率 {qg:.3f}（基座 {qb:.3f}，长度偏好版 {qp:.3f}）")
print("质量偏好样例:", sg[0][:40])
质量偏好版: 故事词命中率 0.000（基座 0.332，长度偏好版 0.000）
质量偏好样例: rrillllllllligrdgrdsgropllllll

典型读数出乎预料：质量偏好版也塌到了 0.00——但塌法不同。长度版的退化和偏好同向（就是要长，长成了垃圾）；质量版的退化是过拟合：策略把训练时那几百条”高分样本”的对数概率推到极高，生成时翻来覆去吐同几个碎片。这是一个比”偏好要对”更深的教训：

  1. 对齐需要两个条件——偏好方向对（裁判准），且步子稳（别离参考模型太远）。我们的 DPO 没有显式 KL 罚，\(eta\) 又只是软杠杆，好偏好照样能把分布挤垮（真实系统里 KL 罚、早停、奖励模型迭代都在干这件事）；
  2. 两种塌法对应 Goodhart 的两种形态：代理错位（长度版）与过优化（质量版）——前者骗裁判，后者把裁判背下来了。

对齐的全部重量由此压在两根支柱上：“偏好从哪来、有多准”（测量问题）与”优化走多远、怎么刹车”（控制问题）——9.2 的哲学欠条在此立据。

32.6 本章 Loss 账本

问题 回答
在优化什么 loss？ 偏好对的 DPO 损失——奖励的变形。全书主角（loss）迎来了它最主观的化身：“更好”被写成数学
数据从哪来？ 成对的人类比较（我们的长度/质量规则）；标注者的偏见即模型的偏见
买到了什么能力？ 超越模仿的行为塑形；风格、详略、安全性的可定向调节；SFT 之后主要的行为升级通道
没买到什么？ 偏好之外的真理（代理永动机）；免于 Goodhart 的免疫力——KL 罚、奖励迭代都只是减速带
  • Goodhart 三部曲 → 7.4 的可验证奖励（把裁判从”人类偏好”换成”对错”——绕开主观性的另一条路，但也带来新的边界）；9.2 的评测危机是它的终极形态；
  • “谁的偏好写进 loss” → 预训练（文本作者）→ SFT（示范者）→ RLHF（标注者）——这条权力链是 AI 治理讨论的技术骨架；
  • DPO 的消元 → “数学简化改变工程格局”家族（与 word2vec≈PMI 分解、注意力替代对齐同列）；
  • KL 罚项 → “别离参考太远”是一切安全微调的通用保险丝（7.4 的 RLVR 同样带它）。

  • 跳过：理论性质证明；
  • 历史注：先读 Ouyang et al. (2022) 的 RLHF 三部曲（上一章的论文时光机），再读本文的”三步变一步”——两篇之间的工程代差，就是”把约束优化写成监督学习”这一行数学的重量。另注：DPO 标题里”secretly a reward model”（暗藏的奖励模型）——每个 loss 都是某个价值判断的显影，这句话可以当全书的注脚。

32.7 遗留问题

  1. 主观偏好有 Goodhart，客观对错呢？——把裁判换成”答案对不对”的自动验证，优化会走向哪里？（→ 下一章 RLVR：可验证奖励的强化学习，以及推理模型）；
  2. 我们的策略用 LoRA 挂在冻结底座上——能力与行为分离的工程化，会给”对齐的稳固性”带来什么问题？（→ 8.x 与 9.2 的”对齐浅层性”讨论）。

32.8 练习

  1. 造轮子：给 DPO 加 KL 罚（对策略与参考的平均对数概率差加惩罚项），重跑长度偏好——退化会被抑制吗？抑制的代价是什么？
  2. 预测再运行：把 β 从 0.3 调到 0.05 与 3.0，退化的速度与最终形态各怎么变？（β 是”离参考多远”的杠杆。）
  3. 消融：偏好数据里把 chosen 换成”长而格式正确”（长句但由真词组成）——欺骗还发生吗？代理缺陷的哪个成分（长度本身 vs 与质量的错位）才是欺骗的必要条件？
  4. 论文映射：用四问账本并排拆 RLHF 与 DPO——两者”买到”栏的差异（稳定性/简单性 vs 灵活性/探索能力）如何决定各自今天的领地？
  5. 进阶：实现 PPO 的最小版（在 DPO 的同任务上：策略采样→奖励打分→裁剪的重要性采样更新），对照收敛速度与稳定性——亲手体会 DPO 论文动机里的”工程之痛”。
Note练习答案

练习 1：退化被推迟而非消除（KL 拉住的是”离参考的分布距离”，代理极端往往不需要走太远——重复单字符的 KL 其实不大，这正是它成为”作弊捷径”的原因之一）。代价：学习变慢、真改进也被一起刹车。

练习 2：小 β 温和缓慢（最终仍退化）；大 β 激进——常在数值上把对数概率差推到饱和（σ 进 0/1，梯度消失），训练提前”假死”。β 是对齐强度的旋钮，甜点区狭窄。

练习 3：不发生（或大幅减轻）——“长而正确”与真目标正相关，优化代理顺带优化真目标。欺骗的必要条件是错位而非极端；这条判据可以反过来用于审查自家偏好数据：代理的极端形态（把规则推到 limit）还是不是好答案？
