11  AlexNet 时刻：历史为什么发生在 2012

2012 年 9 月 30 日，ImageNet 竞赛（ILSVRC）的成绩公布：一个叫 SuperVision 的队伍把图像分类的 top-5 错误率从前一年的 25.8%、当年第二名 26.2%，直接打到 15.3%。领先不是一步，是一个时代。队伍是 Hinton 的两个学生——Alex Krizhevsky 与 Ilya Sutskever——加上 Hinton 本人；机器是他们租的，模型是我们前三章所有零件的总装：卷积结构 + relu + dropout + GPU。本章要回答的问题是本章标题：为什么是 2012？ 这个问题的答案，是理解此后十年（包括 LLM 时代）一切产业逻辑的钥匙。

Tip算力需求

A 级：笔记本 CPU · 全部实验合计约半分钟。

  • 算力：消费级 GPU 经 CUDA（2007）变得可编程；两张 GTX 580（合计约 3 GB 显存、约 1.5 TFLOP/s）就是 AlexNet 的全部装备——今天一台游戏本胜它十倍；
  • 数据：ImageNet（李飞飞团队，2009 年上线）提供 22000 类、1500 万张标注图片——“数据工程”第一次成为 AI 研究的一等公民，此前最大的基准（CIFAR-10）只有 6 万张；
  • 认知：2011 年的主流观点是：神经网络在 1990s 已经输给 SVM/boosting，视觉的特征还是要手工设计（SIFT、HOG）；深度学习被视为少数几个多伦多老人的执念；
  • 关键事实：AlexNet 的每一个零件都不是 2012 年发明的（卷积 1989、relu 2010、dropout 2012 年初、GPU 训练 2010 年前后已有人尝试）——2012 年发生的是总装。

11.1 本章问题

我们不重演 AlexNet 本身（它需要 GPU 和 ImageNet，属于 B 级实验，3.1 章会给一个缩小版），而是解剖它的历史条件。历史学家的标准问法：如果抽掉任何一块基石，2012 还会发生吗？具体到可实验的两块：

  1. 算力：GPU 的加入到底买了什么？我们用自己的矩阵乘法实测”算力账本”；
  2. 数据：没有 ImageNet 量级的数据，这套方法还成立吗？我们实测”数据账本”。

11.2 历史中的尝试（包括弯路）

视觉特征的手工时代（1980s–2011）。从 SIFT（1999）到 HOG（2005），视觉进步的主线是人类设计更好的特征描述子 + 浅层分类器。这条路线的哲学正是 1.2 章符号主义的延续：知识来自专家头脑。它在小数据上精致、可靠、可解释——并且在天规模数据面前停摆：特征没有随着数据变多而变好。

GPU 的非显然性。用游戏显卡做通用计算（GPGPU）在 2008 年前后仍属旁门：编程痛苦（早期要伪装成图形调用）、数值稳定性差、学术圈视之为”工程杂耍”。CUDA 把门槛降下来后，第一个吃螃蟹的训练仍需要勇气与手艺——Krizhevsky 写了定制的卷积核。历史条件不只是”GPU 存在”，而是”GPU 可编程 + 有人愿意为深度学习忍受它”。

总装的三人组。Krizhevsky（工程与直觉）、Sutskever（信念与理论品味）、Hinton（三十年深耕连接主义的信用背书）——1.2 章地下时期的三件套（换语言、硬问题、火种）在 2012 年兑成了一次总爆发。教训：范式复活的最后一步需要一个”不可辩驳的演示”——道理 1986 年就懂，但说服世界需要一个数字：15.3%。

赛后的雪崩。2013 年起几乎所有参赛队伍转向深度学习；工业界（Google 收购 DNNresearch 团队）跟进；GPU 厂商 NVIDIA 转型”AI 公司”。一个演示改变资源流向，资源流向改变研究的经济学——这条因果链将在 6.1（GPT-3）与 7.3（ChatGPT）再演两次。

给你两笔账，先手算再实测：

  1. 算力账：AlexNet 单次前向约 \(7\times10^8\) 次乘加；训练一遍（120 万张图 × 90 epoch）约 \(10^{18}\) FLOPs。用笔记本 CPU 的矩阵乘实测速度（下一节会测，先猜量级），需要多久？两张 GTX 580 实际用了 5–6 天。从这两个数推出 GPU 的加速比，再想想：如果没有这个加速比，2012 年的博士还能不能做完这个课题？
  2. 数据账：一套固定的网络与训练流程，训练样本数从 6 涨到 40（小一号的同构实验），真实误差会怎么降？先在纸上画你预期的曲线（横轴 n，纵轴真实误差）——尤其预测最小数据点处会发生什么（提示：1.6 章的过拟合）。

写完两笔账再运行。

11.3 核心思想

The Bitter Lesson（Sutton, 2019）正式登场。这一页纸的短文值得全文背诵，其核心：

七十年来，AI 研究反复上演同一幕：依赖人类知识精巧设计的短期胜利，被”蛮力搜索 + 学习”的长期胜利碾过——后者随算力指数增长而复利。

2012 年是这条规律在视觉领域的总清算：三十年手工特征（人类知识的注入）被”大数据 + 大算力 + 通用学习”一次性超越。而 1.2 章的范式之争（专家规则 vs 学习）正是同一剧本的上一场演出——Sutton 的判决书其实 1986 年就已写好草稿。

历史条件 = 算力 × 数据 × 方法，三者同时就绪。抽掉任何一块：没有 GPU，训练一轮要数月，课题不可行；没有 ImageNet，百万参数网络在小数据上只会过拟合（1.6 章的账），方法不可信；没有 2010–2012 的工具箱（relu/dropout/初始化），深度网络训不动，方法不可行。三者各就各位的时间窗口恰好是 2009–2012——历史为什么发生在 2012？因为再早一步，任何一块都缺位。

演示的杠杆。研究史不只有论文与证明，还有”改变资源流向的数字”。15.3% 之于深度学习，等于后来 175B 参数之于 GPT-3（6.1）、对话流畅度之于 ChatGPT（7.3）——范式战争的裁决从来靠演示，不靠论证。

11.4 从零实现

我们的两个”账本实验”——不重演 AlexNet，而是实测它的两块基石。

实验一：算力账本。 测你机器上 numpy 矩阵乘法的吞吐（BLAS 加速的 numpy 已是 CPU 上限）：

import time

import numpy as np

for n in (256, 512, 1024):
    A = np.random.rand(n, n)
    B = np.random.rand(n, n)
    t0 = time.time()
    C = A @ B
    dt = time.time() - t0
    print(f"{n:>4}x{n:<4} 矩阵乘: {dt*1000:6.1f} ms = {2*n**3/dt/1e9:6.1f} GFLOP/s")
 256x256  矩阵乘:    1.5 ms =   21.8 GFLOP/s
 512x512  矩阵乘:    1.7 ms =  156.5 GFLOP/s
1024x1024 矩阵乘:    6.2 ms =  344.8 GFLOP/s

三个读数（典型值：25 / 120 / 350 GFLOP/s 左右，随机器浮动）：

  • 规模越大，单位吞吐越高——矩阵乘的算术强度高，缓存友好，这正是它成为深度学习基本货币的原因（算子的经济学决定架构的演化，5.3 的伏笔）；
  • 取 100 GFLOP/s 估算：AlexNet 训练一遍 \(10^{18}\) FLOPs ≈ \(10^7\) 秒 ≈ 四个月（且是优化过的今天 CPU；2012 年的 CPU 更慢）。两张 GTX 580 合计约 3 TFLOP/s，即使按 30% 利用率也有约 1 TFLOP/s——几天。加速比两个数量级，恰好是把”不可行的课题”变成”一个学期的博士课题”的距离；
  • 你的笔记本（约 \(10^{11}\) FLOP/s）比 1986 年的 VAX（约 \(10^6}\) FLOP/s）快五个数量级——本书卷一的每一个”分钟级”实验，在当年都是”一学期级”。

实验二：数据账本。 固定网络与训练流程，只改训练点数，看真实误差（不是训练误差）：

f = lambda x: np.sin(2*x + 0.7) + 0.5*np.sin(4*x - 0.3)
Xd = np.linspace(-3, 3, 200).reshape(-1, 1)
Yd = f(Xd)

from dlbook.nn.mlp_numpy import MLPNumpy
from dlbook.utils import set_seed

set_seed(42)
for n in (6, 15, 40):
    rng = np.random.default_rng(7)
    X = np.sort(rng.uniform(-3, 3, n)).reshape(-1, 1)
    Y = f(X) + rng.uniform(-0.25, 0.25, (n, 1))
    m = MLPNumpy(1, [32, 1], seed=42)
    for _ in range(3000):
        m.backward(X, Y)
        m.step(0.02, momentum=0.9)
    tr = float(np.mean((m.forward(X) - Y) ** 2))
    de = float(np.mean((m.forward(Xd) - Yd) ** 2))
    print(f"n={n:>2}: 训练误差={tr:.4f}  真实误差={de:.4f}")
n= 6: 训练误差=0.0016  真实误差=2.7951
n=15: 训练误差=0.0221  真实误差=0.1030
n=40: 训练误差=0.0332  真实误差=0.0438

读数（对照你的预测）：n=6 时训练误差近乎零、真实误差 2.8——网络完美背下了六个点，对函数本身一无所知（1.6 的过拟合在最小数据点上的复现）；n=15 时 0.10；n=40 时 0.04——真实误差随数据近一个数量级地下降。这就是 ImageNet 存在的理由：在数据贫瘠的时代，“学出特征”是无本之木；百万级标注图片让通用学习第一次在视觉上有账可算。

11.5 消融实验

数据的”饱和点”探针。AlexNet 之后”堆数据”成为信仰，但数据账本有没有饱和点？把实验二延伸：n=40 → 100 → 400（网络与步数不变），观察真实误差的边际递减。当曲线趋平时，瓶颈从数据转移到容量（网络太小学不动更多结构）——“数据-容量-算力”三角的移动平衡，这个平衡在 2022 年被 Chinchilla 重新计算（6.2 的伏笔），在数据墙时代再次成为主角（9.2）。

for n in (40, 100, 400):
    rng = np.random.default_rng(7)
    X = np.sort(rng.uniform(-3, 3, n)).reshape(-1, 1)
    Y = f(X) + rng.uniform(-0.25, 0.25, (n, 1))
    m = MLPNumpy(1, [32, 1], seed=42)
    for _ in range(3000):
        m.backward(X, Y)
        m.step(0.02, momentum=0.9)
    de = float(np.mean((m.forward(Xd) - Yd) ** 2))
    print(f"n={n:>3}: 真实误差={de:.4f}")
n= 40: 真实误差=0.0438
n=100: 真实误差=0.0276
n=400: 真实误差=0.0234

问题 回答
在优化什么 loss？ AlexNet：百万图上的 softmax 交叉熵——目标本身 1989 年就有人用；变的是这个目标能被推到多低

  • 算子的经济学（矩阵乘吞吐） → 5.3 “Transformer 为什么赢”的答案之一、今天 GPU/TPU 架构设计的出发点。

11.9 练习

  1. 算力账本延伸：查一张今天消费级 GPU 的理论 FLOP/s，重算 AlexNet 训练时间；再估 GPT-3（约 \(3\times10^{23}\) FLOPs）在单卡上需要多久——从而理解”万卡集群”不是炫富而是必需。
  2. 预测再运行：实验二里把网络从 32 宽改成 128 宽，n=6 的真实误差会怎么变？变大（记更多噪声）还是变小（拟合更好）？运行并解释。
  3. 消融：实验二改成 sigmoid 激活 + 朴素初始化（回到 1990s 配置），数据账本的曲线整体会怎么移动？数据还能救它吗？
  4. 论文映射：用四问账本拆 ImageNet 论文（2009）——注意它的”买到的能力”一栏几乎全是基础设施而非模型。
  5. 进阶（历史推理）：写半页”反事实 2012”：如果 CUDA 晚五年出现，视觉领域的演进路径会怎样？手工特征会多统治几年？谁会填补空白？
Note练习答案

练习 1 参考数字：GPT-3 约 \(3\times10^{23}\) FLOPs ÷ 单卡 \(10^{12}\) FLOP/s（30% 利用率）≈ \(10^{11}\) 秒 ≈ 三千年——万卡且高度并行的集群把它压到数月。“规模化”的每一分钱都花在这道除法里。

练习 2：n=6 时真实误差大概率变大——容量越大，背噪声背得越狠（1.6 的容量-过拟合互换）；n=40 时可能略变好。数据账本的斜率依赖容量，两者是联动的。

练习 3：整条曲线整体抬高且低数据端尤其惨烈——1990s 配置下”加数据”的边际收益更小，这正是当年”数据无用论”能流行的技术土壤。工具箱不只是工具，它重新定价了数据。

练习 5 提示：注意因果的双向性——没有 GPU 也就训不出对 GPU 的需求，硬件-算法的共生回路会晚启动，但一旦启动会补涨。反事实推演的价值在于识别”哪些是必然（趋势），哪些是偶然（时点）“。
