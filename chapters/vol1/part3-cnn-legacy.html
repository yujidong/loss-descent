15  CNN 的遗产：特征层级与预训练-微调

到 2014 年，一个安静的革命完成了：卷积网络学到的那些滤波器与特征，被证实可以整块搬走。在一个大数据集上预训练的网络，切掉头、换上新任务的小分类器，用很少的样本微调一下，就能在完全不同的视觉任务上打败从头训练的专用模型。“CNN features off-the-shelf”（现成的 CNN 特征）成了 2014 年论文标题里的流行语。这个实践后来有了一个将统治整个领域的名字：预训练 + 微调。本章用一个小实验重演它的诞生，并指出：这是卷积时代留给 LLM 时代最重要的遗产。GPT 的整个范式就长在这个模板上。

Tip算力需求

A 级：笔记本 CPU · 全部实验合计约 2 分钟。

  • 算力：预训练一个大网络成为”一次性投资”，微调成为”廉价消费”。算力经济学第一次把研究切分成”基础模型层”与”应用层”；
  • 数据：ImageNet 的通用特征被证明对宠物、家具、医学影像都有用。“数据的知识以权重形式沉淀”这个观念开始成立；
  • 认知：Zeiler & Fergus（2013 (Zeiler and Fergus 2014)）用反卷积可视化打开了黑箱一角：底层是边缘与色块，中层是纹理与部件，顶层是物体。特征层级从假设变成了照片；
  • 产业：Caffe 的 Model Zoo（模型动物园）出现。预训练权重的下载与复用成为日常操作；“fine-tuning”进入每个工程师的词汇表。

15.1 本章问题

  1. 特征是什么：卷积网络的中下层到底学到了什么，使它能被搬走？
  2. 迁移的账：预训练的特征 + 少量新样本，比起从零训练，好多少？好在什么条件下成立？

15.2 历史中的尝试（包括弯路）

弯路：为每个任务从零训练。 AlexNet 之后的 2013 年，多数团队仍为每个新任务从零训练。昂贵、缓慢、且小数据任务上效果差。打破惯性的是三个”off-the-shelf”式的演示：Donahue et al. 与 Razavian et al.（均 2014）直接拿 ImageNet 预训练特征 + 线性 SVM，横扫十几个小数据任务；OverFeat（2014 (Razavian et al. 2014)）把同一网络同时用于分类、定位、检测。迁移不是新想法（1.2 的符号主义也在”复用知识”），新的是知识的载体变成了权重。

可视化的助攻：Zeiler & Fergus（2013）的反卷积可视化让”层级特征”从传说变成照片。第一层的 Gabor 边缘、第三层的纹理组合、第五层的物体部件。人们第一次可以指着一张图说：这就是它学到的知识。可解释性作为”研究说服力工具”的第一次大胜（这场戏在 LLM 时代将重演，卷三）。

范式定型：fast R-CNN（2015）等检测框架把”ImageNet 预训练主干 + 任务头微调”固化成标准工作流。到 2018–2019，同一个模板将原样搬到 NLP（ELMo、BERT）。注意这个时间差：视觉的范式转型比 NLP 早了整整四年，等的东西叫 Transformer（5.2）。

实验设计题（先写方案再看书中的方案）：

设定：你有一个在”干净域”（噪声 0.15）、300 个样本上训练好的卷积特征提取器。现在来了一批只有 10 个样本的新数据，且来自更脏的域（噪声 0.3）。任务相同（图案分类）。

设计两个互相竞争的方案并预测胜负与分差：

  • 方案甲：只用这 10 个样本，从零训练整个网络；
  • 方案乙：冻结预训练的特征提取器，只训一个线性分类器。

提示三个思考点：(1) 10 个样本够从零训练几个参数？(2) 预训练特征遇到域偏移还可靠吗？(3) 线性分类器你打算用本书哪一号老朋友？

写完再往下。方案乙的最后一件零件，是对第 1 章的一次回访。

15.3 核心思想

特征层级 = 知识的权重形态。卷积网络的中下层学到的是边缘、纹理、部件这类跨任务通用的中间构件；任务特异的信息集中在顶层。这个”通用底座 + 专用顶盖”的结构是迁移可行的物质基础。也是”知识”第一次以可搬运的权重而非不可搬运的规则（1.2 的专家系统）或不可复用的标注（数据本身）的形态存在。

预训练 + 微调 = 算力与知识的再定价。预训练把”从数据中学通用知识”变成一次性重投资；下游任务用小样本廉价消费它。这个分工一旦成立，研究社区的经济学随之改写：谁预训练了最好的底座，谁就定义了下游的天花板。这句话将在 6.1（GPT-3）与 7.x（对齐）逐字兑现，并最终引发”基础模型”（foundation model）这个词的诞生。

冻结 + 线性探针 = 特质分离术。冻结特征只训线性分类器（linear probe），测量的是”表征里线性可读出多少任务信息”；放开设微调，测量的是”表征可适配多远”。这两种测量今天仍是 LLM 可解释性与能力评估的标准工具（卷三将反复使用）。它们全部诞生于本章这个时代。

15.4 从零实现

import numpy as np

from dlbook.data import make_shifted_pattern
from dlbook.nn import Perceptron, SimpleConvNet
from dlbook.utils import set_seed

set_seed(42)

# 阶段一：在干净域(噪声 0.15)的 300 个样本上预训练特征提取器
Xa, ya = make_shifted_pattern(n=300, noise=0.15, seed=0)
conv = SimpleConvNet((12, 12), out_ch=8, kernel=3, padding=1, hidden=16, seed=0, pool=True)
rng = np.random.default_rng(0)
first = None
for ep in range(80):
    order = rng.permutation(len(Xa))
    for s in range(0, len(Xa), 32):
        i = order[s : s + 32]
        l = conv.backward(Xa[i], ya[i])
        if first is None:
            first = l
        conv.step(0.03, momentum=0.9)
print(f"预训练: loss {first:.3f} -> {l:.4f}")

def features(X):
    Hr = np.maximum(conv.conv.forward(X), 0.0)
    return Hr.mean(axis=(2, 3))  # 全局平均池化后的 8 维特征
预训练: loss 1.000 -> 0.0166

阶段二：10 个脏样本上的两种消费方式。

Xb, yb = make_shifted_pattern(n=10, noise=0.3, seed=5)    # 小样本 + 域偏移
Xe, ye = make_shifted_pattern(n=400, noise=0.3, seed=9)   # 同域测试集

# 方案乙：冻结特征 + 感知机探针（1.1 章的老朋友重出江湖）
probe = Perceptron(8)
probe.train(features(Xb), yb, epochs=100)
acc_probe = float(np.mean([probe(f) == t for f, t in zip(features(Xe), ye)]))
print(f"方案乙 预训练特征 + 感知机探针: test_acc = {acc_probe:.3f}")

# 方案甲：同样 10 个样本，从零训练整个网络
scratch = SimpleConvNet((12, 12), out_ch=8, kernel=3, padding=1, hidden=16, seed=0, pool=True)
for ep in range(80):
    order = rng.permutation(len(Xb))
    for s in range(0, len(Xb), 10):
        i = order[s : s + 10]
        scratch.backward(Xb[i], yb[i])
        scratch.step(0.03, momentum=0.9)
acc_scratch = float(np.mean((scratch.forward(Xe).ravel() > 0) == (ye > 0)))
print(f"方案甲 从零训练:            test_acc = {acc_scratch:.3f}")
方案乙 预训练特征 + 感知机探针: test_acc = 0.853
方案甲 从零训练:            test_acc = 0.677

典型读数：探针 0.85，从零 0.68。在只有 10 个样本、域还偏移的苛刻条件下，预训练特征把一张 8 维的”隔脏”垫在了任务与新数据之间。注意两件事：

  1. 参数账：探针只训 9 个参数（感知机），从零要训 241 个。10 个样本对 9 个参数勉强够用，对 241 个是杯水车薪（样本/参数比 1:24）；
  2. 感知机的复活：第 1 章被 XOR 判死刑的感知机，在这里干得漂亮。不是它变强了，是特征变好了。1969 年的判决书写的是”单层线性分类器学不出非线性特征”；而特征工程/学习把这个前提抽掉了。老工具在新语境里的复活，是研究史反复出现的省钱戏法。

15.5 消融实验

域偏移有多伤？ 把测试域的噪声从 0.3 调回 0.15（与预训练同域），再看探针成绩。分离”特征迁移”与”域适应”两笔贡献：

Xe2, ye2 = make_shifted_pattern(n=400, noise=0.15, seed=9)
acc_same_domain = float(np.mean([probe(f) == t for f, t in zip(features(Xe2), ye2)]))
print(f"探针在干净域测试: {acc_same_domain:.3f}（脏域是 {acc_probe:.3f}）")
探针在干净域测试: 0.785（脏域是 0.853）

同域测试接近满分。特征本身是好的，脏域上丢掉的那十几个点全是域偏移的代价（分布变了、特征还在工作但信噪比下降）。预训练不是万能险：它搬的是特征，不是对新分布的适应（分布偏移问题将贯穿到卷三的对齐与评测）。

15.6 本章 Loss 账本

问题 回答
在优化什么 loss？ 预训练：干净域上的图案分类 MSE；下游：特征空间里的线性分类（感知机准则，1.1 的账）。两个 loss、两份数据、一个网络
数据从哪来？ 预训练 300 样本（干净域）+ 下游 10 样本（脏域）。“大数据学底座、小数据学顶盖”的完整缩影
买到了什么能力？ 10 样本条件下的 0.85 vs 0.68；知识与算力的复用经济
没买到什么？ 域适应（消融实验里那十几个点）；下游任务与预训练差异过大时的迁移失效（负迁移的真实存在）
  • 预训练 + 微调 → 本书的下半场主线：BERT/GPT 把模板搬到 NLP（6.1），RLHF 的 SFT 阶段就是”预训练底座 + 对齐头”（7.x）。你在本章亲手跑的 241 参数实验，与 GPT-4 的后训练在结构上是同一件事；
  • 线性探针 → LLM 可解释性（在隐藏状态上线性探测”模型是否知道某事实”）与能力评估的标准工具（卷三）；
  • 模型动物园 → Hugging Face Hub 的史前形态；“权重作为知识载体” → 开源权重生态的法理基础；
  • Zeiler-Fergus 可视化 → 可解释性研究的谱系（卷三的 probing/SPA/特征可视化）。

Razavian, A., Azizpour, H., Sullivan, J. & Carlsson, S. (2014). CNN features off-the-shelf: an astounding baseline for recognition. CVPR Workshops.

  • 读什么：表格。一个冻结的 ImageNet 特征 + 线性 SVM 在十几个数据集上刷新或接近 SOTA；标题里的 astounding（令人震惊的）是学术圈少见的诚实用词；
  • 跳过：SVM 细节；
  • 历史注：配套读 Zeiler & Fergus (2013) Visualizing and understanding convolutional networks（特征层级的”照片”）。两篇合起来是”看见 + 搬走”：先证明特征通用，再证明特征可售。范式转型的两步舞，此后每次转型（NLP 2018、多模态 2021）都重跳一遍。

15.9 练习

  1. 造轮子：把探针从感知机换成小型 MLPNumpy（8-8-1），冻结特征重训。比感知机好多少？“线性可读”与”可读”的差距就是这份增量。
  2. 预测再运行：下游样本从 10 涨到 50，两个方案的差距会扩大还是缩小？到 300 时呢？先画预测曲线再跑。迁移的价值随下游数据量单调递减（直到交叉），这是预训练经济学的核心曲线。
  3. 消融：把预训练的噪声从 0.15 提到 0.3（与下游同域），探针在脏域的成绩会好于原来的跨界版吗？这是”同域脏预训练 vs 跨域净预训练”的一次小型对照。
  4. 论文映射：用四问账本拆 Razavian 2014。注意它几乎全部的”买到”都记在基础设施栏（一个可复用的底座），模型本身的贡献栏反而是空的。
  5. 进阶：实现”部分微调”梯度：解冻最后一层卷积、其余冻结，10 样本微调 20 epoch。与全冻结、全微调三方对照，你能找到”冻多少”的最优点吗？
Note练习答案

练习 2：差距随下游数据量收窄。50 样本时从零训练已能到 0.8+，300 时两者趋同甚至反超（预训练特征未必是本任务最优）。这条”迁移收益 vs 数据量”的递减曲线，就是后来 BERT 时代各类”数据预算-微调策略”图表的玩具版；LoRA（7.2）的一切讨论都发生在曲线的左端。

练习 3：大概率不如跨界净版。脏域预训练的特征信噪比天然更低，而”见过干净图案”的抽象恰好扛得住脏域的输入。但也有例外种子（小样本噪声大），值得多跑几个种子看方差。预训练实验的方差管理本身就是真实工程痛点。

练习 5 提示：最优点通常在”靠近输入的层冻结”。通用性从底到顶递减。这就是微调时代”要不要解冻 backbone”的标准决策树的玩具版。
