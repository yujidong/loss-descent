16  CNN 的边界：序列问题为何难

卷一收官。在跨入序列世界之前，我们要亲手给卷积时代划一条边界——不是唱衰，是精确测量它的势力范围。CNN 的全部力量来自两个先验（局部 + 平移），这两个先验在图像上是恩赐，到了序列上就变成了枷锁：句子里决定下一个词的信息可能在五个词之前，也可能在五百个词之前——依赖的距离是不定的，而卷积的窗口是固定的。本章用一个最小实验把这条边界拍在桌上，然后推门进入卷二。

Tip算力需求

A 级：笔记本 CPU · 全部实验合计约 1 分钟。

  • 算力：序列模型（即将登场的 RNN）在 GPU 上的并行度天生不如卷积——算力的偏好开始悄悄影响架构演化（5.3 的主题埋线）；
  • 数据：互联网文本成为下一个金矿，词级依赖动辄跨越数十词；
  • 认知：NLP 的主流是词向量 + 特征工程（4.4 的 word2vec 刚出现）；把”阅读”当作序列建模的想法正在成形；
  • 关键事实：卷积并未死于序列——WaveNet (Oord et al. 2016)（2016）用空洞卷积把窗口指数式撑大，证明”固定窗口”还有最后一滴油水可榨；但真正的王座要等循环与注意力（Part 4 与 5）。

16.1 本章问题

把”窗口不够”变成一个可证伪的实验：

序列是 16 个比特，任务只看其中一个特定位置（距末尾 8 步）的值。一个只看末尾 k 个输入的模型——

  1. \(k=3\)：能学到多好？（这是数学问题还是训练问题？）
  2. \(k=10\)：呢？

16.2 历史中的尝试（包括弯路）

把图像方案硬搬到文本（弯路）。早期尝试把句子当”一维图像”做卷积（text-CNN，Kim 2014）——在短文本分类上意外好用（n-gram 检测器），但生成与翻译这类需要逐位置输出、看任意远上下文的任务上，固定窗口捉襟见肘。分类可以只看局部特征袋，生成必须照顾全局——这个差别定义了序列建模的真正难度。

空洞卷积的最后一搏（WaveNet, 2016）。窗口不再紧挨着滑动：第 \(l\) 层的卷积每隔 \(d_l\) 个位置取一个输入，\(d_l\) 逐层翻倍——\(L\) 层的等效感受野随 \(2^L\) 指数增长，10 层即可覆盖上千个时间步。它撑起了 2016–2018 的语音合成（说出了谷歌助手的声音），却仍有一个软肋：感受野再大也是预设的——依赖在感受野之外照样抓瞎，且所有位置共享同一套”看哪里”的模式。

命运的伏笔：解决”不定距离依赖”的正确答案其实已经发表（注意力，Bahdanau 2014——5.1 的主角），但世界要先在循环结构上绕一个大圈。答案常常早于问题被需要——研究史的又一常态。

任务：16 比特序列，\(y = x_{16-8}\)（回看 8 步）。两个候选模型，都只读序列末段：

  • 模型甲：一维卷积，核宽 3，取末位输出（它只能看见最后 3 个比特）；
  • 模型乙：同上，核宽 10（能看见最后 10 个比特，含第 8 步前那个位置）。

先写下你的预测：

  1. 甲的测试准确率是多少？——注意这不是”大概”的问题：信息论规定了它的上限，请精确推算（提示：目标比特在它的视野里吗？视野外的比特与目标独立吗？）；
  2. 乙需要多少训练才能到 1.0？
  3. 设计追问：把回看距离从 8 改成 12，乙还能撑住吗？——“撑得住的依赖距离”就是这个架构的势力范围图。

写完再运行。

16.3 核心思想

固定窗口 = 截断的信息通道。窗口外的输入与输出统计独立（本任务里目标比特就是窗口外的一个独立随机比特）——任何只看窗口的模型，其最优策略是输出边缘分布，准确率被钉死在概率地板上（二分类即 0.5）。这不是训练不足，是信息论层面的不可解——你无法从看不见的比特里读出它的值。

序列的三重难点（相对图像）：

  1. 变长：句子长短不一，全连接与固定窗口都要为每种长度打补丁；
  2. 不定距依赖：决定下一个词的信息可能在任何距离上——固定感受野与”任意距离”结构性地不匹配；
  3. 因果性：生成时只能看过去不能看未来——架构要内建时间的方向。

卷积对 1 有补丁（自适应池化）、对 3 有补丁（因果卷积），唯独对 2——不定距——是原理性的短板。突破口有二：让网络带状态（循环，RNN——把”读过的东西”压缩进一个可携带的隐藏向量）或让每个位置动态选择看哪里（注意力）。前者是卷二前半的主角，后者是终局答案。

一条重要的对称性：n-gram 语言模型（下一个 Part 的开场）与末位卷积在信息结构上同构——都是”固定窗口看历史”。所以本章的边界实验同时也是 4.1 的预告片：n-gram 的病与 text-CNN 的病是同一个病。

16.4 从零实现

dlbook.nn.Conv1D 已就位。模型 = 一维卷积 + relu + 只取末位输出（因果式的最小演示）+ 线性头：

import numpy as np

from dlbook.data import make_seq_task
from dlbook.nn import Conv1D
from dlbook.nn.mlp_numpy import MLPNumpy
from dlbook.utils import set_seed

set_seed(42)

Xtr, ytr = make_seq_task(n=500, length=16, dist=8, seed=0)
Xte, yte = make_seq_task(n=500, length=16, dist=8, seed=1)
print("任务: y = 序列倒数第 8 个比特（视野内还是外，取决于窗口宽度）")


def train_window_net(k, epochs=60, lr=0.05):
    conv = Conv1D(8, k, seed=0)
    head = MLPNumpy(8, [1], seed=1)
    rng = np.random.default_rng(0)
    for ep in range(epochs):
        order = rng.permutation(len(Xtr))
        for s in range(0, len(Xtr), 50):
            i = order[s : s + 50]
            Z = conv.forward(Xtr[i])[:, :, -1]  # 只取末位（因果式输出）
            Hr = np.maximum(Z, 0.0)
            pred = head.forward(Hr)
            dA = 2.0 * (pred - ytr[i].reshape(-1, 1)) / len(i)
            dHr = head.backward_from(Hr, dA)
            conv.backward(dHr[:, :, None] * (Z > 0.0)[:, :, None])
            conv.step(lr)
            head.step(lr, momentum=0.9)
    Zte = np.maximum(conv.forward(Xte)[:, :, -1], 0.0)
    return float(np.mean((head.forward(Zte).ravel() > 0) == (yte > 0)))


for k in (3, 10):
    print(f"窗口 k={k:2d}: test_acc = {train_window_net(k):.3f}")
任务: y = 序列倒数第 8 个比特（视野内还是外，取决于窗口宽度）
窗口 k= 3: test_acc = 0.486
窗口 k=10: test_acc = 1.000

典型读数：\(k=3\) 拿到 0.51（概率地板）；\(k=10\) 到 1.00。与你在「停一停」的推算对照：目标比特在位置 \(16-8=8\)（0 起数），\(k=3\) 的窗口只覆盖最后三个位置——目标在视野外，任何学习算法都只能输出边缘分布；\(k=10\) 把它框进来后，问题退化为一层线性可读的映射。

16.5 消融实验

势力范围图：固定 \(k=10\)，扫回看距离——

for dist in (2, 4, 8, 12):
    Xtr_d, ytr_d = make_seq_task(n=500, length=20, dist=dist, seed=0)
    Xte_d, yte_d = make_seq_task(n=500, length=20, dist=dist, seed=1)

    conv = Conv1D(8, 10, seed=0)
    head = MLPNumpy(8, [1], seed=1)
    rng = np.random.default_rng(0)
    for ep in range(60):
        order = rng.permutation(len(Xtr_d))
        for s in range(0, len(Xtr_d), 50):
            i = order[s : s + 50]
            Z = conv.forward(Xtr_d[i])[:, :, -1]
            Hr = np.maximum(Z, 0.0)
            pred = head.forward(Hr)
            dA = 2.0 * (pred - ytr_d[i].reshape(-1, 1)) / len(i)
            dHr = head.backward_from(Hr, dA)
            conv.backward(dHr[:, :, None] * (Z > 0.0)[:, :, None])
            conv.step(0.05)
            head.step(0.05, momentum=0.9)
    Zte = np.maximum(conv.forward(Xte_d)[:, :, -1], 0.0)
    acc = float(np.mean((head.forward(Zte).ravel() > 0) == (yte_d > 0)))
    print(f"回看距离 {dist:2d} (窗口 k=10): test_acc = {acc:.3f}")
回看距离  2 (窗口 k=10): test_acc = 0.798
回看距离  4 (窗口 k=10): test_acc = 1.000
回看距离  8 (窗口 k=10): test_acc = 0.518
回看距离 12 (窗口 k=10): test_acc = 0.504

前三个距离（2、4、8）都在窗口内——全对；距离 12 越出窗口——跌回地板。一条由 \(k\) 画死的硬边界，这就是势力范围图。真实语言里”有用的上下文距离”没有上限——固定窗口的死刑判决书由这张小图签署。

16.6 本章 Loss 账本

问题 回答
在优化什么 loss？ 回声任务的 MSE——loss 降不下去的原因第一次是信息不可得，而非模型不可训
数据从哪来？ 合成序列；历史上是文本与语音
买到了什么能力？ 精确测得固定窗口架构的能力边界；确认”信息在视野外 = 数学上的不可解”
没买到什么？ 不定距依赖、变长输入的优雅处理——序列时代的全部门票
  • 固定窗口 ↔︎ n-gram（4.1 开场即与本章汇合：语言模型的最古老形态就是窗口模型）；
  • 空洞卷积 → 音频合成（WaveNet）与某些高效的序列混合层——卷积在 LLM 时代仍有驻军（部分架构的局部混合用卷积做，注意力的”邻居折扣”思想与之同源）；
  • “视野外的信息” → LLM 的上下文窗口（8.x）：今天的大模型仍然活在某种窗口里，长上下文研究是本章主题在 2020s 的直系续集；
  • 因果式末位输出 → 自回归语言模型的输出头（4.1 的正式登场：每个位置预测下一个 token）。

16.9 练习

  1. 造轮子：给 Conv1D 加 dilation 参数（窗口每隔 d 取一个输入），用两层 dilation=1,2 的空洞卷积在 dist=12 上复得满血——亲手重演 WaveNet 的感受野指数增长。
  2. 预测再运行：把 \(k=3\) 的训练样本加到一亿个，\(k=3\) 的测试准确率会改善吗？为什么”加数据”在这个病例上无效？（这是全书第一次遇到”数据治不了的病”。）
  3. 消融：把末位输出改成全局平均池化输出，\(k=10\) 还能解回声任务吗？（提示：平均会稀释位置信息——位置敏感的任务与池化天然打架。）
  4. 论文映射：用四问账本拆 Kim 2014——它的成功局限在”局部特征袋够用”的任务上，账本第四问怎么写？
  5. 进阶：设计一个”两段依赖”任务（\(y\) 依赖位置 -3 或 -12，由另一个比特选择），证明任何固定单一窗口都不能全覆盖——不定距依赖的最小反例。把你的构造写给任何一个卷积模型试试。
Note练习答案

练习 2：不会改善——目标比特与窗口内输入统计独立，贝叶斯最优就是边缘分布 0.5。数据买不到视野外的信息；这个事实在 LLM 时代的版本叫”上下文外幻觉”（模型对窗口外的问题只能编），9.2 再会。

练习 3：全局平均后，末位与首位信息的区别被抹平——\(k=10\) 的优势消失，成绩跌回 0.5 附近。需要位置信息时要用”保留位置维度的头”（我们的末位头）或位置编码（5.2 的正式解法）。

练习 5 提示：单一窗口 \(k\) 覆盖 \([-k, -1]\)；两个候选位置 -3 与 -12 至少有一个在任意 \(k<12\) 的窗口外。双分支（不同 \(k\)）+ 门控可以硬解，但门控信号本身也要看全局——你已经在重新发明”动态选择看哪里”，即注意力的雏形。
